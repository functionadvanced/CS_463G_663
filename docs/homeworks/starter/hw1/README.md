# Homework 1 starter

This package contains everything needed to develop and check Homework 1.

## Files

- `hw1.py`: the only file you edit and submit.
- `check_hw1.py`: public examples and a legal-path checker.

## Run the public checks

```bash
python check_hw1.py
```

The checker validates path format, movement, keys, doors, and the public shortest lengths. It does not reveal the hidden tests or the required state representation.

Upload only `hw1.py` to Canvas.
