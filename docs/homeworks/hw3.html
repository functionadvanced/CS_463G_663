Background and reference sheet

Propositional logic treats each symbol such as \(P\) or \(Q\) as one truth-valued statement. First-order logic adds objects, predicates, variables, and quantifiers, allowing a formula to describe relationships among members of a domain. Throughout this homework, parentheses and the scope of each quantifier are part of the meaning—not merely typography.

Form Read as Useful equivalence
\(\neg P\) not \(P\) flips the truth value
\(P \land Q\) \(P\) and \(Q\) true only when both are true
\(P \lor Q\) \(P\) or \(Q\) false only when both are false
\(P \rightarrow Q\) if \(P\), then \(Q\) \(\neg P \lor Q\)
\(P \leftrightarrow Q\) \(P\) exactly when \(Q\) \((P\rightarrow Q)\land(Q\rightarrow P)\)

Clause-form workflow

Use the same explicit pipeline for each CNF conversion:

  1. eliminate \(\leftrightarrow\) and \(\rightarrow\);
  2. move negations inward with De Morgan’s laws and quantifier duality;
  3. standardize bound variable names apart;
  4. move quantifiers to a clear prenex form when useful;
  5. Skolemize existential variables, recording which universal variables each Skolem function depends on;
  6. distribute \(\lor\) over \(\land\); and
  7. write the result as a set of clauses, with universal quantifiers implicit.
TipUnification and resolution reminders

A substitution must be applied consistently everywhere, and a variable cannot be replaced by a term containing that same variable (the occurs check). Resolution combines clauses containing complementary literals, applies the required unifier, and removes the resolved pair. In a refutation proof, deriving the empty clause means that the knowledge base together with the negated query is inconsistent.

1. Truth tables and classification

For each formula, construct the complete truth table and classify it as exactly one of the following:

  • tautology: true under every truth assignment;
  • contradiction: false under every truth assignment; or
  • contingent: true under at least one assignment and false under at least one assignment.

Analyze these formulas:

  1. \[(P \lor Q) \rightarrow R\]
  2. \[\neg(P \lor Q) \leftrightarrow (\neg P \land \neg Q)\]
  3. \[((P \rightarrow Q) \land (Q \rightarrow R)) \rightarrow (P \rightarrow R)\]

Include columns for the useful subexpressions, not only the final result.

2. First-order logic translation

Translate each sentence into first-order logic. State the domain and define every predicate or constant you introduce.

  1. Everyone who studies AI is intelligent.
  2. Some student loves logic but does not love probability.
  3. Every professor teaches at least one course.

Use quantifier scope and parentheses carefully. Equivalent, well-defined predicate names are acceptable.

3. Conversion to clause form

Convert each formula to conjunctive normal form. Show implication elimination, movement of negations, standardization or Skolemization when needed, and distribution into clauses.

  1. \[\forall x\, ((P(x) \lor Q(x)) \rightarrow R(x))\]
  2. \[\neg \exists y\, \forall x\, (Loves(x,y) \lor Hates(x,y))\]

For the second formula, make the dependency of any Skolem function explicit. In the final clause set, universal quantifiers may be left implicit.

4. Unification

Find a most general unifier (MGU) for each pair, or explain why no unifier exists. Show the substitutions in the order you derive them and give the composed substitution at the end.

  1. \(P(A,x,f(y))\) and \(P(A,B,f(z))\)
  2. \(Knows(John,x)\) and \(Knows(y,Bob)\)

5. Resolution proof

Use refutation resolution to prove that query \(Q\) follows from this knowledge base:

\[P \lor Q\] \[\neg P \lor R\] \[\neg R\]

Your proof must:

  1. negate the query;
  2. list the initial clause set;
  3. identify the parent clauses and resolved literal at every step; and
  4. end with the empty clause \(\square\).

Presentation checklist

  • Every variable and predicate is defined.
  • Parentheses make quantifier and connective scope unambiguous.
  • Each truth table includes all assignments exactly once.
  • CNF work distinguishes a formula from its clause-set representation.
  • The unifier is applied consistently to both expressions.
  • The resolution proof states why deriving \(\square\) establishes entailment.
