Lecture 14: CSP Consistency

Peizhong Ju

Constraint Propagation

  • Enforce constraints before making deeper search choices.
  • Remove values that cannot participate in any valid solution.
  • Detect impossible partial assignments early.

Search decides what to try; propagation decides what is no longer worth trying.

Consistency

A variable assignment is consistent when it satisfies the relevant constraints.

Level Also called Requirement
1-consistency Node consistency Each variable satisfies unary constraints
2-consistency Arc consistency Each value has support in each connected variable
3-consistency Path consistency Any consistent pair can be extended to a third variable
k-consistency General form Any consistent k-1 assignment can be extended

1-Consistency

Definition

  • A unary constraint applies to one variable.
  • A problem is 1-consistent if every variable has at least one valid value satisfying unary constraints.

Example

  • Variable: age X.
  • Domain: \{10,15,20,25,30\}.
  • Constraint: X \ge 18.
  • Reduced domain: \{20,25,30\}.

2-Consistency

  • A binary constraint applies to a pair of variables.
  • A problem is 2-consistent if every value of one variable has a supporting value in each connected variable.

For each value x \in D(X_i), there must exist a value y \in D(X_j) such that the constraint between X_i and X_j is satisfied.

k-Consistency

  • A CSP is k-consistent if any consistent assignment to k-1 variables can be extended to any k-th variable.
  • A CSP is strongly k-consistent if it is j-consistent for all j \le k.
  • Higher levels of consistency can prune more values.
  • But computing them becomes expensive quickly.

In practice, algorithms often enforce 2-consistency and sometimes 3-consistency, but rarely much higher.

Example: 2-Consistency

Consider variables X,Y:

D(X)=\{1,2,3,4\}, \quad D(Y)=\{2,3,4\}

Constraint: X < Y.

Values of X

  • X=1 supported by Y=2,3,4.
  • X=2 supported by Y=3,4.
  • X=3 supported by Y=4.
  • X=4 has no support.

Values of Y

  • Y=2 supported by X=1.
  • Y=3 supported by X=1,2.
  • Y=4 supported by X=1,2,3.

Remove 4 from D(X); then the arc is consistent.

Arc Consistency

A variable X_i is arc-consistent with X_j if every value in D(X_i) has at least one supporting value in D(X_j).

Arc consistency is directional: checking (X_i,X_j) asks whether values in X_i have support in X_j.

AC-3 Algorithm

AC3(CSP):
Q = all arcs (Xi, Xj) connected by a constraint
 
while Q is not empty:
remove an arc (Xi, Xj) from Q
 
if Revise(Xi, Xj) removed values from D(Xi):
if D(Xi) is empty:
return failure
 
for each Xk in Neighbors(Xi), except Xj:
add (Xk, Xi) to Q
 
return reduced domains

AC-3: What Each Part Does

Step Meaning
Initialize queue Every arc may need checking
Remove an arc Focus on one directional constraint
Revise Delete unsupported values
Empty domain No solution can satisfy current constraints
Re-add neighbors A deletion can make nearby arcs inconsistent

Revise Function

Revise(Xi, Xj):
removed = false
 
for each x in D(Xi):
if no y in D(Xj) satisfies the constraint:
remove x from D(Xi)
removed = true
 
return removed

Revise is the pruning operation; AC-3 is the scheduler that decides which arcs to revisit.

Why Consistency Matters

  • CSP structure gives us domain-independent pruning methods.
  • Consistency computation is the core of constraint propagation.
  • Stronger consistency can reduce more search.
  • But stronger consistency can itself become expensive.

The goal is not to eliminate search completely; it is to make the remaining search much smaller.
