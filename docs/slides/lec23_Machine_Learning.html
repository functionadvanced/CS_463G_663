Machine Learning

Learning agents improve their performance from observations.

Why Learning?

Learning is valuable when:

  • Designers cannot anticipate every possible situation.
  • The task changes over time.
  • We do not know how to write the rules directly.
  • Data reveals patterns that are hard to specify by hand.

Instead of programming every rule, we design a learning process.

What Is Machine Learning?

Machine learning enables computers to learn from data and make predictions or decisions without being explicitly programmed for every case.

A typical ML system:

The learned model is both a hypothesis about the world and a piece of software.

Three Major Categories

Category Training signal Typical tasks
Supervised learning Labeled examples Classification, regression
Unsupervised learning Unlabeled data Clustering, dimensionality reduction
Reinforcement learning Rewards from interaction Control, game playing, robotics

Supervised Learning

Supervised learning learns from input-output pairs.

Component Meaning
Features Inputs used for learning
Labels Correct outputs during training
Model Function learned from examples
Loss function Error measure between prediction and label

Examples:

  • Classification: spam vs. not spam.
  • Regression: house-price prediction.

Unsupervised Learning

Unsupervised learning looks for structure without labels.

Common tasks

  • Clustering.
  • Dimensionality reduction.
  • Anomaly detection.

Use cases

  • Customer segmentation.
  • Visualization.
  • Fraud detection.

The question changes from “what is the correct answer?” to “what structure is hidden in the data?”

Reinforcement Learning

Reinforcement learning studies agents that learn by interacting with an environment.

Core pieces:

  • Agent, environment, state, action, reward, policy.

Relationship to GOFAI

GOFAI

  • Explicit symbols and rules.
  • Search over states or plans.
  • Logic-based reasoning.

Machine learning

  • Data-driven model fitting.
  • Search over model parameters or hypotheses.
  • Pattern recognition and prediction.

ML can be viewed as searching for a model that explains data, but the search space and methods are often very different from symbolic AI.

k-Nearest Neighbors

k-NN is an instance-based supervised learning algorithm.

To classify a new point, find the k closest training examples and let them vote.

It is simple, useful, and a good first example of how “learning” can be stored in the training data itself.

k-NN Algorithm

function KNNPredict(query, trainingData, k)
distances = []
for each (x, label) in trainingData
append(distances, (distance(query, x), label))
neighbors = kSmallest(distances, k)
return majorityVote(neighbors)

k-NN Picture

The label depends on the local neighborhood and the choice of k.

PCA

Principal Component Analysis is an unsupervised method for dimensionality reduction.

It finds new axes that capture as much variance as possible.

Why use it?

  • Reduce dimension.
  • Remove redundancy.
  • Improve efficiency.
  • Visualize high-dimensional data.

Key operation

Project data onto a smaller number of principal components.

PCA and SVD

PCA can be computed using singular value decomposition:

X=U\Sigma V^T

Matrix Role
U Left singular vectors
\Sigma Singular values, related to variance
V Right singular vectors, principal components

The principal components are the directions in V.

RL Example: Robot Navigation

A robot explores a maze and learns how to reach the exit.

RL component Maze example
Agent Robot
Environment Maze
State Current position
Action Up, down, left, right
Reward +10 for exit, -1 for wall
Policy Strategy for choosing actions

Policy Improvement

Initial policy

Move randomly; turn when blocked.

Intermediate policy

Avoid walls; avoid paths that previously failed.

Learned policy

Prefer high-reward paths while still exploring enough to improve.

RL is learning from consequences, not from labeled answers.

What to Remember

  • Machine learning builds models from data.
  • Supervised learning uses labels; unsupervised learning finds structure; RL learns from reward.
  • k-NN classifies by local similarity.
  • PCA reduces dimension by finding high-variance directions.
  • RL connects learning with sequential decision-making.
