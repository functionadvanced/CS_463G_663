What Does the Rule Actually Permit?

A lab’s access rule says:

If a person has a valid badge, the door unlocks.

Must the door stay locked for everyone without a valid badge?

No. The rule requires unlocking for badge holders. It leaves other cases open.

Invite the viewer to choose an answer before revealing it. Return to this question after introducing implication and again in the final policy activity.

The lecture moves from representation to evaluation, then to equivalent formulas and policy debugging. Allow time to work through the truth tables and pause at the translation and policy questions. The next lecture introduces entailment and proof procedures.

The access example describes a simplified Boolean decision for one person at one time. It does not prescribe a real building’s safety or emergency policy.

Logic and Propositions

Logic represents knowledge precisely and supports reasoning from it.

A proposition is a statement that is true or false once its context is fixed.

Sentence A proposition?
“The lab door is unlocked now.” Yes, even if we have not checked
“Two plus three equals six.” Yes, and it is false
“Unlock the door!” / “Is it unlocked?” No, a command / question
“x is greater than three.” Needs a value for x to stand alone

Classical logic uses T = true, F = false. Not knowing the value does not create a third value.

Connect to constraint satisfaction problems (CSPs): logical formulas also accept some assignments and reject others. An agent can use such rules to represent requirements and infer consequences. A correctly evaluated formula may still represent the wrong requirement.

Fix the person, door, and time when natural language leaves them implicit. The open expression involving x is not a closed proposition by itself. Specifying x makes it evaluable. Quantified statements come later.

One Symbol, One Stable Meaning

An atom is a proposition we treat as indivisible.

For one person, at one access decision:

Symbol Atomic proposition
B The person has a valid badge
V The person is an approved visitor
E An emergency is active
D The door unlocks

Propositional logic combines atoms using logical connectives. A truth assignment gives each atom a value, T or F.

Keep B, V, E, and D fixed throughout the access example. Generic truth tables use P and Q, which can stand for any propositions. A symbol names a statement, not a numerical quantity or a command.

If the person or time changes, a new statement may be needed. An atom can describe a complicated fact in English, but propositional logic does not inspect its internal structure.

NOT and AND

  • Negation (NOT): \neg P flips the value of P.
  • Conjunction (AND): P \land Q is true only when both inputs are true.
P Q \neg P P \land Q
T T F T
T F F F
F T T F
F F T F

“Valid badge and no emergency”: which atom does NOT apply to?

B \land \neg E. Only the emergency condition is negated.

Introduce a truth table as a systematic list of all input assignments and their output values. P and Q produce four rows. The negation column ignores Q, while AND depends on both inputs.

Inclusive OR and Exclusive OR

Disjunction (OR) means at least one. Exclusive OR (XOR) means exactly one.

\underbrace{B \lor V}_{\text{at least one}} \qquad\qquad \underbrace{(B \lor V) \land \neg(B \land V)}_{\text{exactly one}}

An approved visitor may also have a badge. Use ordinary OR if either method, including both together, is acceptable.

Read every column as one assignment. The first column is the difference between inclusive and exclusive OR. XOR’s first factor rules out neither, and its second factor rules out both. Clarify an English “or” before formalizing it.

An Access Condition, Step by Step

“A valid badge or approved visitor, and no active emergency.”

\varphi = (B \lor V) \land \neg E

\varphi (phi) names this condition. Try B=\text{false}, V=\text{true}, E=\text{false}.

  1. B \lor V = \text{true}.
  1. \neg E = \text{true}.
  1. \varphi = \text{true}.

First translate authorization as B OR V, no emergency as NOT E, then combine them with AND. Parentheses group the authorization condition. Phi names a formula, not a new independently assigned atom.

Pause before evaluating. Each advance highlights the corresponding operation. Evaluate from the assigned leaves upward. The operation uses its immediate child values, not the English wording again.

If E changes to true, NOT E becomes false and the root becomes false, even though authorization remains true. This gives the next truth table a concrete row to check.

In n atoms, a full table needs 2^n rows. This exponential growth motivates more efficient reasoning methods in the next lecture.

Implication Has One Violating Case

Implication: B \rightarrow D means “if valid badge, then door unlocks.”

B is the premise. D is the conclusion.

An implication is false only when its premise is true and its conclusion is false.

A false premise makes the rule vacuously true: neither no-badge case violates it.

The diagram supplies the four rows of the implication truth table. Ask which case violates the rule before discussing the two cases without a badge.

The rule’s truth value is different from the door’s truth value: the rule can be true while D is false. Logical truth here describes compliance with a statement.

“Vacuously” is a technical term for the convention, not another truth value. A visitor or another access method could explain D when B is false. The formula does not claim such an explanation exists, only that this assignment is compatible with the rule.

Material implication describes truth conditions, not causation or timing. It does not itself specify a complete policy.

“If” and “Only If”

  • B \rightarrow D: badge is sufficient, enough to guarantee unlocking.
  • D \rightarrow B: badge is necessary, required whenever unlocking occurs.

“The robot moves only if its battery is ready.” M = moves, R = ready. Which direction?

M \rightarrow R. Read it as “movement requires readiness.”

An English sentence may mention the conclusion first: “D if B” still means B implies D. Necessary does not mean sufficient. A ready battery need not force motion.

Converse, Inverse, and Contrapositive

Equivalence (\equiv): formulas agree on every truth assignment.

Name Formula Equivalent to the original?
Original B \rightarrow D Yes
Converse: reverse the arrow D \rightarrow B No
Inverse: negate both parts \neg B \rightarrow \neg D No
Contrapositive: reverse and negate \neg D \rightarrow \neg B Yes

Try B=\text{false}, D=\text{true}. Which formulas are true?

Original and contrapositive: true. Converse and inverse: false.

Logical equivalence means agreement on every assignment. A single differing assignment refutes it. The contrapositive rules out exactly the original rule’s violating case: a valid badge but no unlock.

The converse and inverse are equivalent to each other, though not to the original. “Not equivalent” does not mean they differ on every row.

A Biconditional Requires Both Directions

“The door unlocks if and only if the badge is valid.”

B \leftrightarrow D \quad\equiv\quad (B \rightarrow D) \land (D \rightarrow B)

B D B \leftrightarrow D
T T T
T F F
F T F
F F T

The biconditional is true when both sides have the same value. Iff abbreviates “if and only if.”

Both arrows hold in the F/F row. Compare XOR: it accepts the two mismatching rows, whereas the biconditional accepts the two matching rows. This badge-only policy is a temporary example. The final policy allows visitors too.

Negation Scope and De Morgan’s Laws

“Not both” means at least one fails. “Neither” means both fail.

English Formula Equivalent formula
Not both \neg(B \land V) \neg B \lor \neg V
Neither \neg(B \lor V) \neg B \land \neg V

De Morgan: negate each part and swap AND with OR. The symbol \equiv means logical equivalence.

With a badge but no visitor approval, not both is true and neither is false. One assignment with different outputs disproves equivalence between those two requirements.

Each row of the table gives a De Morgan equivalence. Keep parentheses until negation scope is clear. The next slide verifies the first law for arbitrary propositions P and Q.

Checking De Morgan’s Law

\neg(P \land Q) \equiv \neg P \lor \neg Q

P Q \neg(P \land Q) \neg P \lor \neg Q
T T F F
T F T T
F T T T
F F T T

The output columns match on every assignment. Equivalent formulas can replace each other inside a larger formula.

Work through the T/F row: AND is false, so its negation is true. NOT P is false but NOT Q is true, so their OR is true. Matching every output establishes equivalence.

Agreement on only one row would be insufficient. A biconditional can be true in one assignment without its two sides being logically equivalent across all assignments.

Useful Equivalence Laws

Law Equivalent formulas
Double negation \neg\neg P \equiv P
Identity P \land \text{true} \equiv P
P \lor \text{false} \equiv P
Domination P \lor \text{true} \equiv \text{true}
P \land \text{false} \equiv \text{false}
Idempotence P \land P \equiv P
P \lor P \equiv P
Implication (P \rightarrow Q) \equiv \neg P \lor Q
Distributivity: AND over OR P \land (Q \lor R) \equiv (P \land Q) \lor (P \land R)
Distributivity: OR over AND P \lor (Q \land R) \equiv (P \lor Q) \land (P \lor R)

OR over AND: either P is true, or both Q and R are true.

Explain the names with truth conditions rather than asking for memorization. Identity leaves the value unchanged. Domination fixes it regardless of P. Idempotence means a repeated input changes nothing. The implication law reproduces the implication’s four-row table.

Boolean logic has both distributive laws. The operator outside the parentheses distributes over the operator inside. AND over OR requires P and at least one of Q or R. OR over AND allows P alone, otherwise it requires both Q and R. For the second law, if P is true, both clauses on the right are true. If P is false, the right side reduces to Q AND R.

Optional check: rewrite NOT (P implies Q) as P AND NOT Q. This uses the implication law, De Morgan’s law, and double negation in that order.

A Redundant Condition Disappears

AND over OR, used backward, factors out a shared requirement:

(P \land Q) \lor (P \land R) \equiv P \land (Q \lor R)

Both forms require P, together with at least one of Q or R.

B = valid badge, L = lab open.

(B \land L) \lor (B \land \neg L)

Here P=B, Q=L, R=\neg L. Factor out the shared B:

\equiv B \land (L \lor \neg L)

Since L \lor \neg L is always true, B \land \text{true} \equiv B.

The formula allows either value of L. Only the valid badge is required.

P, Q, and R are arbitrary propositions. In the left form, either successful branch requires P. In the right form, P is required once alongside the choice between Q and R. This is AND distributing over OR, used in reverse to factor out the repeated requirement.

The example says “valid badge and lab open, or valid badge and lab not open.” A valid badge is required in both branches. The law of excluded middle makes L or NOT L true. Identity finishes the rewrite. Neither the algebra nor the truth table decides whether the resulting policy is appropriate for the real task.

Testing an Incomplete Access Policy

Intended: unlock exactly when authorized and no emergency is active.

Proposed rules: Rule 1 ((B \lor V) \land \neg E) \rightarrow D and Rule 2 D \rightarrow \neg E.

Try B=\text{false}, V=\text{false}, E=\text{false}, D=\text{true}. Do both rules hold?

Rule 1: \text{false}\rightarrow\text{true} is true.

Rule 2: \text{true}\rightarrow\text{true} is true.

Counterexample: both written rules hold, but an unauthorized person gets in.

Point to the no-authorization state and the open door throughout the evaluation. The counterexample satisfies the written rules but violates the intended requirement. This does not make the two written rules logically inconsistent. They simply permit too many assignments.

Phi is the earlier condition (B OR V) AND NOT E. Rule 1 requires access for eligible people. Rule 2 prohibits unlocking during an emergency. Neither requires authorization whenever unlocking occurs. The missing direction is D implies B OR V.

Both Directions Specify the Decision

D \leftrightarrow ((B \lor V) \land \neg E)

What must D be in each case?

Situation Required D
Valid badge, emergency active F
Approved visitor, no badge, no emergency T
Neither authorization method, no emergency F

The forward direction requires unlocking for eligible people. The reverse direction requires both authorization and no emergency whenever unlocking occurs. Adding D implies B OR V to the original pair gives the same complete Boolean decision.

This completes the simplified specification for these four atoms. It does not account for hardware failure, time delays, or other access mechanisms that the example omits.

Takeaways

  • Atoms: give each symbol one stable meaning.
  • Connectives: distinguish OR, XOR, implication, and biconditional.
  • Translation: check “only if” and negation scope.
  • Evaluation: a truth table checks every assignment.
  • Equivalence: preserve all truth values when rewriting.

A formula’s truth conditions may permit more than its author intended. Look for an unwanted assignment that still satisfies the written rules.
