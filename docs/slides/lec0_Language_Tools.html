Python brings the essential AI toolkit together

Each tool extends the same readable language with a different AI capability.

Why Python?

Python is the default language for most AI teaching, research, and prototyping.

What makes it useful

  • Clear syntax for algorithms.
  • Huge ecosystem for data and ML.
  • Easy to connect to APIs and local tools.

What to expect

  • You will read and write Python code.
  • You will use common Python libraries like NumPy, Matplotlib, and PyTorch.

Installing Python

Recommended practical options:

Option Good for Link
Python installer Minimal setup python.org
Anaconda or Miniconda Scientific Python environment anaconda.com
uv Fast modern package/project manager docs.astral.sh/uv

Pick one setup and keep it stable. Most beginner pain comes from mixing several Python installations.

Seek help from YouTube, AI tools, or classmates if you get stuck on installation. The course is about AI, not Python setup.

Basic Python Grammar

name = "Ada"
scores = [90, 85, 100]

for score in scores:
    if score >= 90:
        print(name, "did great")
    else:
        print(name, "can improve")

What matters:

  • Indentation defines blocks.
  • Variables do not need declared types.
  • Lists, dictionaries, loops, and functions show up constantly.

Functions and Data Structures

def accuracy(predictions, labels):
    correct = 0
    for y_hat, y in zip(predictions, labels):
        if y_hat == y:
            correct += 1
    return correct / len(labels)

example = {"model": "knn", "accuracy": 0.93}

If you can read loops, functions, lists, dictionaries, and NumPy arrays, you can follow most course code.

Jupyter Notebook

Jupyter Notebook and JupyterLab mix code cells, Markdown explanation, tables, plots, and step-by-step experiments.

Run locally with:

python -m pip install jupyterlab
jupyter lab

Notebook habit: restart the kernel and run all cells before submitting or trusting results.

Google Colab

Google Colab runs notebooks in the browser.

Useful when

  • Your local setup is broken.
  • You want quick access to a GPU.
  • You want to share a notebook easily.

Watch out for

  • Sessions disconnect.
  • Files may not persist unless saved.
  • Package versions can change.
  • Free GPU availability is not guaranteed.

Simple GUI: PySide6

PySide6 is Python binding for Qt.

Use it when you want a small desktop app instead of only scripts or notebooks.

python -m pip install pyside6
from PySide6.QtWidgets import QApplication, QLabel

app = QApplication([])
label = QLabel("Hello AI tools")
label.show()
app.exec()

GUI work is optional, but useful if you want a more polished project demo.

Local LLMs

Ollama runs many language models locally.

ollama pull llama3.2
ollama run llama3.2

Alternative: LM Studio provides a graphical interface for downloading and running local models.

Local models are not required for the course, but they can make a project feel like a real AI application.

Online AI Chatbot/Agents

AI chatbot/agents are optional, but useful when used carefully.

Tool type Examples Good use
AI chatbot ChatGPT Explaining concepts, checking intuition, drafting examples
Coding agent Codex Editing code, testing, refactoring, building course materials
Alternatives Claude, Gemini, Copilot, Cursor, Perplexity Compare explanations and workflows

Use AI chatbot/agents as collaborators, not as a replacement for understanding.

How to Use AI Chatbot/Agents Well

Good prompts include

  • The task.
  • Constraints.
  • Current error or observation.
  • What you already tried.
  • Desired output format.

Better workflow

Instead of:

“Solve this homework.”

Ask:

“Explain why my BFS queue update is wrong without giving me the full solution.”

Hugging Face

Hugging Face is a major hub for:

Suggested Setup for This Course

Minimum:

  • Python 3 installed.
  • A working terminal.
  • JupyterLab or Google Colab.
  • NumPy and Matplotlib.

Recommended later:

  • PyTorch for deep learning.
  • PySide6 for optional GUI projects.
  • Ollama or LM Studio for optional local LLM demos.
  • Hugging Face for modern models and datasets.

What to Remember

  • Python is the common language of AI prototyping.
  • LLM CLI interfaces let coding agents work from project context, shell output, and file diffs.
  • Jupyter Notebook is great for experiments, but keep notebooks reproducible.
  • NumPy, Matplotlib, and PyTorch cover much of the course coding stack.
  • PySide6 and local LLMs are optional project-building tools.
  • ChatGPT, Codex, and similar tools can help, but you still own the reasoning.
  • MCP is one way LLM interfaces connect to external tools, data, and workflows.
  • Hugging Face is useful for current models, datasets, and demos.
