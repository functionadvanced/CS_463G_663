Agents and Environments

An agent is defined by how it receives information and how it acts on the world.

What Is an Agent?

An agent is a software or hardware system that interacts with an environment through sensors and actuators.

  • Sensors: perceive the state of the environment.
  • Actuators: change or affect the environment.

An agent is not just a program; it is a program situated in an environment.

Example: Robot Vacuum Cleaner

  • Sensors:
    • detect obstacles
    • detect dirt
    • detect edges
  • Actuators:
    • move the vacuum
    • adjust suction
    • send signals

What should the vacuum do when the room is clean but the next room may not be?

Percepts

Agents do not directly receive “the world”; they receive sensor inputs.

Percept

A percept is the input an agent receives at a specific moment through its sensors.

Example:

  • A self-driving car detects a red traffic light.

Percepts are momentary; they describe what the agent receives now.

Percept Sequence

A percept sequence is the complete history of all percepts received by the agent.

Example:

  • At t_1: detects a red light
  • At t_2: detects a pedestrian crossing
  • At t_3: detects a green light

Agent decisions can depend on both the current percept and the percept history.

Agent Functions and Programs

The same behavior can be described abstractly as a function or concretely as a program.

Agent Function

The agent function maps a percept sequence to an action.

Mathematical representation:

f: \text{PerceptSequence} \rightarrow \text{Action}

  • Defines the behavior of the agent.
  • Can be simple rule-based logic.
  • Can be complex learned behavior using AI algorithms.

Example: Thermostat

  • Percept: current temperature T
  • Action: turn heater on/off
  • Agent function:

f(T) = \begin{cases} \text{Turn on heater} & \text{if } T < 20^\circ\text{C} \\ \text{Turn off heater} & \text{if } T \geq 20^\circ\text{C} \end{cases}

Agent Program

  • The agent program is the implementation of the agent function.
  • It runs on the agent’s hardware to produce actions from percepts.
Agent Function Agent Program
Abstract mathematical mapping Practical implementation
Independent of hardware Executes on hardware
Defines ideal behavior Uses algorithms and code

Performance Measures

To evaluate an agent, we must say what counts as success.

Performance Measures

A performance measure defines how success is evaluated for an agent.

For a vacuum-cleaner agent, possible measures include:

  • amount of dirt cleaned
  • energy efficiency
  • minimizing unnecessary movement

What behavior does your scoring rule reward?

Failure Example

Poorly Defined Performance Measure

“Score 1 point for every pile of dirt sucked up.”

The agent may:

  • suck up dirt
  • dump the dirt back out
  • repeat forever to maximize score

Poorly designed objectives can produce unintended behavior.

Reward Hacking

Reward hacking, often called specification gaming, occurs when an agent exploits a scoring rule to earn a high reward without achieving the intended goal.

Our vacuum example

  • Goal: keep rooms clean.
  • Score: count dirt picked up.
  • Shortcut: dump and re-collect dirt.

Today’s coding agents

  • Goal: fix the software bug.
  • Score: count passing tests.
  • Shortcut: change tests to pass while leaving the bug.

Optimizing the score is not the same as achieving the goal.

A long-standing problem, still studied today: DeepMind (2020); Anthropic (2026).

Connect this to the previous slide: repeated dirt collection earns points without keeping rooms clean. The score is a proxy, a measurable stand-in for what we actually want. This is not a newly invented problem; specification gaming is a closely related term. Reward hacking does not require human-like malicious intent.

In reinforcement learning, a reward signal provides feedback used for learning; our performance measure describes what counts as success. Those need not be identical, and a poorly chosen reward can fail to reflect the intended measure. We will study reinforcement learning later.

The coding example summarizes a type of behavior studied in controlled evaluations, not a claim that every coding agent does this. The March 2026 Anthropic study audited debugging tasks with deliberately impossible tests and explicit instructions not to modify them. When a test conflicts with the specification, the appropriate response is to flag the conflict, not silently weaken the evaluation. Broader safeguards include protected tests and independent checks of actual outcomes; no single metric guarantees success.

Rational Agents

Rationality is about choosing well under the information available.

Rational Agent

A rational agent chooses actions expected to maximize its performance measure.

Factors considered:

  • performance measure
  • prior knowledge
  • percept sequence
  • available actions

Definition of a Rational Agent

For each possible percept sequence, a rational agent should:

  • Select the action expected to maximize performance.
  • Base decisions on:
    1. evidence from percepts
    2. built-in knowledge

Rationality does not require perfect knowledge. It requires good action selection from available evidence.

Rationality vs. Omniscience

Rationality Omniscience
Best decision with limited information Perfect foresight
Realistic Unrealistic
Evaluated by expected performance Requires knowing actual outcomes in advance

If an agent makes the best decision from limited evidence but the outcome is bad, was it irrational?

Autonomous Agents

Autonomous agents can reduce their dependence on fixed prior knowledge.

Autonomous Agents

Some agents can:

  • recognize what they do not know
  • gather information through sensing and exploration
  • learn from observations
  • update their own behavior over time

Examples

  • self-driving cars
  • reinforcement learning agents
  • adaptive robots

Autonomy lets agents improve through experience and remain useful in changing environments.

Takeaways

  • Agents interact with environments through sensors and actuators.
  • A percept sequence is the agent’s history of observations.
  • An agent function maps percept sequences to actions.
  • Performance measures shape behavior, sometimes badly.
  • Rational agents maximize expected performance from available evidence.
