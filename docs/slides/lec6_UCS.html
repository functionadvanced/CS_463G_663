Uniform-Cost Search

  • UCS is an uninformed search algorithm.
  • It expands the path with the lowest cumulative cost so far.
  • It is BFS-like when all edge costs are equal.
  • It is equivalent to Dijkstra’s algorithm when we stop at a single goal.

UCS is not looking for the fewest actions. It is looking for the cheapest path.

Why BFS Is Not Enough

Unweighted

BFS is optimal when every edge has the same cost.

Weighted

UCS is needed when edge costs differ.

Priority Queue Intuition

Frontier item Path cost
Start -> C 2
Start -> B 4
Start -> C -> D 5
Start -> B -> D 9

The next expanded path is always the cheapest frontier path, not necessarily the shallowest one.

UCS Pseudocode

UCS(G, s, g):
    initialize priority queue Q
    insert path [s] with cost 0
    initialize visited set V

    while Q is not empty:
        path = remove lowest-cost path from Q
        u = final node of path

        if u is the goal g:
            return path and cost(path)

        if u is not in V:
            add u to V
            for each neighbor v of u with edge cost c:
                add path + [v] with cost(path) + c to Q

UCS Guarantees

Works Well When

  • edge costs are non-negative
  • path costs are meaningful
  • the cheapest solution matters

Watch For

  • high memory use
  • many nearly equal-cost paths
  • no optimality guarantee with negative edge costs

Dijkstra’s Algorithm

Dijkstra(G, s):
    set d[v] = infinity for every node v
    set d[s] = 0
    insert (0, s) into priority queue Q

    while Q is not empty:
        remove node u with the smallest d[u]

        for each neighbor v of u with edge cost w(u, v):
            if d[u] + w(u, v) < d[v]:
                d[v] = d[u] + w(u, v)
                insert (d[v], v) into Q

    return all distances d[v]

UCS stops at a goal. Dijkstra keeps going to compute shortest paths to all nodes.

Bidirectional Search

  • Run a forward search from the start.
  • Run a backward search from the goal.
  • Stop when the two frontiers meet.

Instead of roughly O(b^d) nodes, bidirectional search can explore about O(b^{d/2}) nodes from each side.
