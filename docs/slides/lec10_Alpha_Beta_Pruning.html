Alpha-Beta Pruning

Same minimax answer, less search

Alpha-beta pruning avoids branches that cannot affect the final minimax decision.

It changes the amount of work, not the optimal move.

Why Minimax Is Expensive

  • Minimax explores the game tree.
  • With branching factor b and depth d, the full tree can contain O(b^d) nodes.
  • For chess-like games, even a modest search depth can be too large.

Can we get the minimax decision without evaluating every node?

Pruning Intuition

Max’s View

If Max already has a move worth v, Max will not choose a branch that can only become worse than v.

Min’s View

If Min already has a move worth w, Min will not allow a branch that can only become better for Max.

Once a branch cannot change the ancestor’s decision, stop searching it.

Example of Pruning

Alpha-beta pruning tree

The right Min branch can be pruned once it produces a value lower than Max’s already available option.

Alpha and Beta

Symbol Meaning
\alpha Best value Max can guarantee so far along the current path
\beta Best value Min can guarantee so far along the current path

Prune when \alpha \ge \beta.

Step-by-Step

  1. Initialize \alpha = -\infty and \beta = +\infty.
  2. Traverse the game tree depth first.
  3. At Max nodes, update \alpha = \max(\alpha, \text{current value}).
  4. At Min nodes, update \beta = \min(\beta, \text{current value}).
  5. Stop exploring a branch when \alpha \ge \beta.
  6. Continue until every relevant branch is evaluated or pruned.

Alpha-Beta in Short

At Max Nodes

  • Max wants high values.
  • If a child value reaches or exceeds \beta, Min will avoid this branch.
  • Stop searching the remaining children.

At Min Nodes

  • Min wants low values.
  • If a child value reaches or falls below \alpha, Max will avoid this branch.
  • Stop searching the remaining children.

Alpha-Beta Pseudocode: Max Branch

AlphaBeta(node, depth, alpha, beta, maximizingPlayer):
if depth == 0 or node is terminal:
return utility(node)
 
if maximizingPlayer:
value = -infinity
for each child in node.children:
value = max(value, AlphaBeta(child, depth - 1, alpha, beta, false))
alpha = max(alpha, value)
if alpha >= beta:
break # prune branch
return value

At a Max node, update \alpha; prune as soon as \alpha \ge \beta.

Alpha-Beta Pseudocode: Min Branch

AlphaBeta(node, depth, alpha, beta, maximizingPlayer):
if depth == 0 or node is terminal:
return utility(node)
 
else: # minimizing player
value = +infinity
for each child in node.children:
value = min(value, AlphaBeta(child, depth - 1, alpha, beta, true))
beta = min(beta, value)
if alpha >= beta:
break # prune branch
return value

At a Min node, update \beta; the same prune test \alpha \ge \beta applies.

Imperfect Decision Making

Real games are often too large to search to terminal states.

Technique Idea
Cutoff search Stop at a fixed depth or time limit
Evaluation function Estimate utility of a non-terminal state
Heuristics Use domain knowledge to evaluate promising states

Forward Pruning

  • Expand only the most promising moves instead of all legal moves.
  • This can reduce the effective branching factor.
  • It is risky: a pruned move might have been important.

Alpha-beta pruning is safe; forward pruning is a heuristic compromise.

Iterative Deepening

  • Search shallowly first, then increase the depth.
  • Example: search 2 plies, then 4 plies, then 6 plies.
  • Keep the best completed result.
  • Do not trust an incomplete final search.

Why is this useful when a game engine has a strict time limit?

Move Ordering

  • Alpha-beta pruning works best when strong moves are searched early.
  • Earlier extreme values make more branches eligible for pruning.
  • In chess-style games, captures and checks are often considered early.

Better move ordering does not change the answer, but it can dramatically change runtime.

Quiescence

  • A fixed depth cutoff can stop at an unstable position.
  • Quiescence search continues until the position is relatively calm.
  • Example: avoid cutting off immediately before or after a major capture.

Cut off when the evaluation is meaningful, not merely when the depth counter says stop.
