Learning Action Probabilities

In policy-based reinforcement learning (RL), learn a policy \pi_\theta(a\mid s) directly. It gives the probability of choosing action a in state s, using parameters \theta.

A stochastic policy samples an action from these probabilities. Model-free learning uses experience without an explicit transition-and-reward model.

Value-based methods learn action values and derive choices from them. Policy-based methods adjust the action rule itself.

Policy-based methods can still learn a value estimate, as actor-critic will show. A stochastic policy and a random environment are different sources of randomness. A policy may also describe continuous actions such as a real-valued steering angle, but today’s worked example uses two discrete choices. Original public-domain robot: https://openclipart.org/detail/325644/toy-robot. Background: supplied Spring 2025 Policy-Based RL Beamer lecture; Sutton and Barto, Reinforcement Learning: An Introduction, second edition, Chapter 13.

A Delivery Choice

At depot D, choose a small job or pickup. For this example, always deliver after reaching pickup stop J. Learn only the initial choice at D.

An episode is one run ending at terminal state F. The discount factor \gamma=0.9 gives later rewards less weight.

The return, total discounted future reward, is 4 for the small job and -1+0.9\cdot8=6.2 for pickup then delivery.

This continues the fictional delivery setting from Lectures 30 and 32. All rewards are invented points. We restrict the policy at J to deliver with probability one, so only the choice at D is parameterized in the numerical policy-gradient example. The environment can have other actions, but this restricted policy family never selects return at J. Reward +8 arrives on entry to F, and later value at F is zero. The learner is not supplied the reward model; exact calculations here let us check its sample-based updates.

A Parameterized Policy

A parameterized policy converts adjustable numbers into action probabilities. Use one real-valued logit \theta, a preference score before conversion:

p=\sigma(\theta)=\frac{1}{1+e^{-\theta}},\qquad \pi_\theta(\text{pickup}\mid D)=p,\quad \pi_\theta(\text{small}\mid D)=1-p.

The sigmoid function \sigma maps any real \theta to a probability between 0 and 1.

Start at \theta=0, so both actions have probability 0.5.

This is a one-parameter Bernoulli policy. A general neural policy can output a vector of logits and convert them to a categorical distribution. Here the scalar theta controls only the D choice; J’s deliver probability remains fixed. Increasing theta increases pickup probability and decreases small-job probability. The plotted probabilities come directly from the sigmoid formula, not training results. All subsequent alternative sample calculations restart at theta=0 unless a new value is explicitly stated.

Expected Return

The objective J(\theta) is the expected return from the starting state. The expectation \mathbb E_{\pi_\theta} averages over episodes generated by the current policy:

J(\theta)=\mathbb E_{\pi_\theta}[G_0].

In our example, with pickup probability p:

J(\theta)=4(1-p)+6.2p=4+2.2p.

At p=0.5, expected return is 5.1, although an individual episode returns either 4 or 6.2.

The learning goal is to improve average return over sampled episodes. A single good outcome does not identify the best policy.

The function J(theta), an objective, is distinct from the pickup-stop label J. We can compute the exact objective in this tiny deterministic environment, but a model-free agent normally lacks that formula. Each episode starts at D. G0 is its full discounted return. The expected-return comparison averages over policy randomness here; in a stochastic environment it also averages over transition and reward randomness. The numerical optimum within this policy family favors pickup, approached as theta tends to positive infinity.

Policy-Gradient Ascent

A gradient \nabla_\theta J describes how changing parameters changes expected return. Gradient ascent takes a small step in the increasing direction:

\theta\leftarrow\theta+\alpha\nabla_\theta J(\theta).

The learning rate \alpha>0 sets the step size. With our single parameter:

\frac{dJ}{d\theta}=2.2p(1-p)=0.55\quad\text{at }p=0.5.

Using \alpha=0.1 and the exact gradient gives \theta=0.055, so pickup probability rises from 0.500 to about 0.514.

We will estimate this gradient from sampled episodes instead of needing the environment’s exact reward formula.

The sigmoid derivative is p(1-p), so the chain rule gives dJ/dtheta = 2.2*p*(1-p). This scalar calculation illustrates the vector-gradient update used by neural policies. An arbitrary finite step is not guaranteed to improve a general nonlinear objective, especially with noisy gradient estimates. We use a small positive learning rate for the arithmetic. The exact gradient is a comparison benchmark rather than information supplied to a model-free agent.

REINFORCE and Return-to-Go

REINFORCE is a Monte Carlo policy-gradient method: collect a complete episode, then use its observed returns to update the policy.

The return-to-go G_t counts rewards from step t onward:

G_t=\sum_{k=t}^{T-1}\gamma^{k-t}r_{k+1}.

T is the number of actions before termination. Reward r_{t+1} arrives after action t. Here T=2, G_0=6.2, and G_1=8.

The dummy index k runs over action steps in the remaining episode. Earlier rewards do not belong to a later action’s return-to-go. We use r_(t+1) consistently, matching Lecture 32. The learner keeps the collection policy fixed during this REINFORCE episode. Reference: Ronald J. Williams (1992), Simple statistical gradient-following algorithms for connectionist reinforcement learning, https://doi.org/10.1007/BF00992696; Sutton and Barto, second edition, Section 13.3. The first paper defines the REINFORCE family; we present its standard episodic policy-gradient form.

The Log-Probability Gradient

The log-derivative identity converts a probability derivative into a form we can sample:

\nabla_\theta\pi_\theta(a\mid s) =\pi_\theta(a\mid s)\nabla_\theta\log\pi_\theta(a\mid s).

Here \log is the natural logarithm. REINFORCE estimates the objective’s gradient using:

\hat g=\sum_{t=0}^{T-1}\gamma^tG_t\, \nabla_\theta\log\pi_\theta(a_t\mid s_t),\qquad \mathbb E[\hat g]=\nabla_\theta J.

The log-probability gradient points toward making the sampled action more likely. Its return weights that direction.

Only policy probabilities need derivatives. The simulator supplies sampled states and rewards. The factor \gamma^t preserves the discounted starting-state objective.

Assume a differentiable policy, theta-independent environment and initial-state distribution, and complete on-policy episodes with suitable regularity. Differentiating trajectory likelihood leaves only policy log-probabilities; no derivative of unknown dynamics is required. Conditional on the history before a_t, the expected log-probability gradient is zero. This makes terms from already observed rewards vanish in expectation and justifies return-to-go without falsely claiming that past rewards and future actions are unconditionally independent. For J=E[G0] with discounted Gt measured relative to t, retain the outer gamma^t. At D, t=0, so the numeric examples have weight one. At fixed-action J the score gradient is zero. Reference: supplied Beamer log-derivative argument, Sutton and Barto Chapter 13, and https://spinningup.openai.com/en/latest/spinningup/rl_intro3.html.

Two Possible Sampled Updates

Restart at \theta=0, p=0.5. At D, the log-probability derivatives are 1-p for pickup and -p for the small job. Also \gamma^0=1.

Sampled action Return G_0 Log-probability derivative Sample gradient g_0
Pickup 6.2 0.5 3.1
Small job 4 -0.5 -2

With \alpha=0.1, a pickup episode gives \theta=0.31; a small-job episode gives \theta=-0.20. Each raises its own sampled action’s probability.

The average sample gradient is 0.5(3.1)+0.5(-2)=0.55, matching the exact gradient. Individual updates can point in different directions.

These are alternative one-episode updates from the same initial theta, not sequential episodes. The derivative of log p is 1-p, and that of log(1-p) is -p. After the pickup sample p becomes sigmoid(.31), about .576885; after the small-job sample p becomes sigmoid(-.2), about .450166. Both raw returns are positive, so the uncentered score update favors whichever action happened to occur. The expected gradient still favors pickup because its return is larger. No theorem says each stochastic update must improve the policy.

A Baseline Reduces Update Noise

A baseline b(s) is a state-dependent reference subtracted from the return. Choose it before the current action, and hold it fixed while computing the actor gradient.

Use the illustrative baseline b(D)=5.1, the current policy’s expected return:

Replace G_t by G_t-b(s_t) in the policy-gradient estimate. An action-independent baseline leaves the expected gradient unchanged.

A well-chosen baseline reduces variance, the variation across sampled updates. The exact value 5.1 is for our illustration; a learner usually estimates it.

At a fixed state, sum_a pi(a|s)*grad log pi(a|s)=grad sum_a pi(a|s)=0. Multiplying by an action-independent baseline therefore contributes zero in expectation. This statement holds while treating the baseline as fixed in the actor derivative. A learned baseline can be a function of state and past training data; avoid using an action-dependent quantity as though it were automatically an unbiased baseline. At p=.5, the two centered sample gradients here both equal .55, compared with 3.1 and -2 before centering. This perfect variance cancellation is special to this symmetric deterministic example, not a general promise. References: supplied Beamer baseline material; Sutton and Barto Section 13.4; Spinning Up, Baselines in Policy Gradients.

Advantage and Its Estimate

V^\pi(s) is expected return following policy \pi. Q^\pi(s,a) is expected return after choosing a once, then following \pi.

The advantage is the action’s expected improvement over that state baseline:

A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s).

At p=0.5, V^\pi(D)=5.1:

Action Q^\pi(D,a) True advantage
Small job 4 -1.1
Pickup 6.2 1.1

Using a learned estimate V(D)=5, the pickup episode instead gives the sampled estimate \hat A_0=G_0-V(D)=1.2.

True advantage is a difference of expected values. A sampled return minus a learned value estimate need not equal it, even though it can provide a useful learning signal. In this deterministic example the discrepancy 1.2 versus 1.1 comes entirely from the inaccurate baseline 5 versus 5.1; stochastic future outcomes could add more noise. Positive reward does not imply positive advantage: the small job returns 4 but performs below the current policy’s mean. With the exact baseline, both alternative score-weighted updates at D become .55, preserving their expected gradient.

REINFORCE with a Baseline

Collect each episode with fixed \theta. Use b(s)=0 or a previously learned state-value estimate.

for each episode
trajectory = SampleEpisode(piTheta)
G = DiscountedReturns(trajectory, gamma)
g = 0
for each step t in trajectory
weight = gammat * (G_t - b(s_t))
g += weight * ScoreGradient(theta, s_t, a_t)
theta += alpha * g

ScoreGradient means \nabla_\theta\log\pi_\theta(a_t\mid s_t). DiscountedReturns computes G_t=r_{t+1}+\gamma G_{t+1} backward, starting from G_T=0.

Use the same collection parameters for all gradients in this update, then collect fresh experience after changing the policy.

This is an on-policy episodic update. The baseline is held fixed during the actor-gradient calculation and learned separately if needed. A minibatch version averages sample gradients from several episodes collected with the same policy; we show one episode for clarity. Gamma^t is episode-relative, with t=0 at each start. Keep sampled actions fixed while differentiating their log-probabilities. The diagram/example policy at J has no learnable choice, but the algorithm applies to general differentiable stochastic policies.

Actor-Critic Roles

  • The actor learns action probabilities \pi_\theta(a\mid s), with parameters \theta.
  • The critic learns a state-value estimate V_w(s), with parameters w.

Temporal-difference (TD) learning forms a target from a reward and an estimated next-state value. The TD error compares that target with the current prediction, allowing updates after each transition.

The actor chooses actions; the critic supplies a value estimate, not an ideal-action label or a transition simulator. A critic may be tabular or a neural network. Bootstrapping can reduce sample-update variability and allow earlier feedback, but an inaccurate critic can bias the actor’s signal. This is not a universal lower-variance or sample-efficiency guarantee. Reference: supplied actor-critic Beamer frames and Sutton and Barto Section 13.5. We use separate actor and critic parameters in the later losses.

A TD Advantage Estimate

Bootstrapping uses a current value prediction inside another learning target. For transition (s_t,a_t,r_{t+1},s_{t+1}):

y_t=r_{t+1}+\gamma V_w(s_{t+1}),\qquad \delta_t=y_t-V_w(s_t).

y_t is the TD target. The TD error \delta_t supplies an advantage estimate.

With \gamma=0.9: y_0=-1+0.9\cdot8=6.2, so \delta_0=6.2-5=1.2.

For a terminal next state, use y_t=r_{t+1} with zero future value.

The current critic values 5 and 8 are stipulated estimates, matching the learned-baseline example on the advantage slide. If V_w equals the true V^pi everywhere, the conditional expectation of the one-step TD error given s,a is A^pi(s,a). With an imperfect critic, delta is an approximate advantage signal, not an exact definition of advantage. The true advantage of pickup under p=.5 is 1.1; this critic produces 1.2 because its D baseline is low. Compute the target and error from pre-update predictions. The terminal reward is received once; do not add it again as a value at F or use the next episode’s start value.

Actor and Critic Losses

A loss is a quantity the optimizer minimizes. These losses implement policy ascent and value learning:

L_{\text{actor}}=-\gamma^t\log\pi_\theta(a_t\mid s_t)\, \operatorname{stopgrad}(\delta_t).

L_{\text{critic}}=\tfrac12\left[V_w(s_t)-\operatorname{stopgrad}(y_t)\right]^2.

Stop-gradient treats a value as a constant during differentiation. In PyTorch, use .detach() for this purpose.

The actor gradient flows through the selected action’s log-probability. The critic gradient flows through its current-state prediction. Compute the shared TD error before either update.

These are single-transition losses for separate actor and critic networks. Minimizing the negative log-probability loss implements theta <- theta + alpha*gamma^t*delta*grad log pi. The critic’s detached target implements a semi-gradient value update. At t=0, theta=0, delta=1.2, and alpha=.1, the scalar actor update is theta=.06 and pickup probability becomes about .515. A tabular critic with step size beta=.5 would update V(D) from 5 to 5.6; a neural critic instead changes its weights via grad_w V_w(D). Neither loss should differentiate through sampled environment outcomes. For this discounted starting-state objective retain gamma^t; dropping that factor changes the time weighting. PyTorch detach reference: https://docs.pytorch.org/docs/stable/generated/torch.Tensor.detach.html.

One Actor-Critic Step

At each episode start, set s to the initial state and weight = 1. Repeat until the task terminates.

(a, logProb) = SampleAction(piTheta(s))
(r, sNext, terminal) = Step(a)
target = r if terminal else r + gamma * Vw(sNext)
delta = target - Vw(s)
actorLoss = -weight * logProb * StopGrad(delta)
criticLoss = (Vw(s) - StopGrad(target))2 / 2
UpdateBoth(actorLoss, criticLoss)
weight *= gamma
s = sNext

SampleAction also saves the sampled action’s log-probability. Step performs the action. UpdateBoth minimizes each network’s loss. Here weight equals \gamma^t.

This is on-policy one-step actor-critic. SampleAction must use the correctly normalized available-action distribution, and logProb must come from that same distribution before parameters change. Both losses use pre-update predictions. For separate networks the detached actor advantage and critic target keep their intended gradient paths independent. Reset the state and weight at a true episode boundary. The terminal flag means task termination; arbitrary collection time limits may require different bootstrap handling. This is explanatory pseudocode, not the homework implementation or a claim about callback timing in the game driver.

Homework 6: Actor-Critic

The Homework 6 assignment and starter apply these ideas to a game agent.

  • Actor outputs: logits, unnormalized action scores, become probabilities for sampling.
  • Action mask: unavailable actions get probability zero. Renormalize over legal actions and save the chosen action’s log-probability from that same distribution.
  • Learning: detach the advantage and bootstrap target in the appropriate losses. Terminal targets use only the final reward.
  • Evaluation: freeze learning while measuring performance against the reference agent.

Which network should receive a gradient from the selected action’s log-probability?

The actor. The critic learns from its own value-prediction loss.

Takeaways

  • A parameterized policy directly represents action probabilities.
  • Policy gradients improve expected return using sampled experience.
  • REINFORCE uses complete episodes and return-to-go.
  • A state baseline can reduce update noise without changing the expected gradient.
  • True advantage is an expected-value difference. Sampled or TD-based advantages are estimates.
  • Actor-critic learns both a policy and a value predictor, using separate gradient paths.

Keep the sampled reward, return, baseline, and advantage estimate distinct when explaining an update.
