Autoregressive Models

Autoregressive models generate structured data one piece at a time, conditioning on what they already generated.

What Means Autoregressive?

“Auto” means the model uses its own previous outputs.

For a sequence:

p(x_1,\ldots,x_T) = \prod_{t=1}^{T}p(x_t\mid x_1,\ldots,x_{t-1})

Generation becomes repeated conditional prediction.

Next-Token Prediction

Example:

p(\text{blue}\mid \text{The sky is})

The sky is ? blue

Autoregressive Generation Loop

function Generate(prompt, model)
sequence = prompt
while not finished
distribution = model(sequence)
next = sample(distribution)
append(sequence, next)
return sequence

Types of Autoregressive Models

Model Core mechanism
RNN Hidden state updated step by step
LSTM RNN with gates and cell state for long dependencies
GRU Simpler gated recurrent unit
Transformer decoder Self-attention over previous tokens
PixelCNN Masked convolution over previous pixels

Recurrent Neural Network

An RNN maps:

f_\theta:(x_t,h_{t-1})\mapsto(y_t,h_t)

Stacked Recurrent Networks

Stacking adds depth at each time step.

Depth helps learn more abstract sequence representations.

LSTM

LSTMs add gates and a cell state.

Component Role
Input gate i_t Controls new information
Forget gate f_t Controls what to erase
Candidate g_t Proposed new content
Output gate o_t Controls exposed hidden state
Cell state c_t Long-term memory path

LSTM Updates

i_t=\sigma(W_{ii}x_t+b_{ii}+W_{hi}h_{t-1}+b_{hi})

f_t=\sigma(W_{if}x_t+b_{if}+W_{hf}h_{t-1}+b_{hf})

g_t=\tanh(W_{ig}x_t+b_{ig}+W_{hg}h_{t-1}+b_{hg})

c_t=f_t\odot c_{t-1}+i_t\odot g_t,\qquad h_t=o_t\odot\tanh(c_t)

GRU

GRU is a simpler gated recurrent unit.

Gate Purpose
Update gate Controls how much previous state is kept
Reset gate Controls how much previous state is used in candidate update

GRUs often train faster than LSTMs while keeping much of the benefit of gated memory.

PixelCNN

PixelCNN generates images pixel by pixel in raster order.

Masked filters prevent the model from looking at future pixels.

Pixel Mask Intuition

seen seen seen
seen current future
future future future

Autoregressive image generation imposes an ordering on pixels, just like text imposes an ordering on tokens.

What to Remember

  • Autoregressive models factor a joint distribution into sequential conditionals.
  • Generation repeats prediction and sampling.
  • RNNs summarize history with hidden states.
  • LSTMs and GRUs improve recurrent memory with gates.
  • PixelCNN applies autoregression to images using masks.
  • Transformers will modernize this idea with self-attention.
