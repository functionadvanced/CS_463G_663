Can the Robot Conclude It May Move?

For this robot, define:

  • B: the battery is ready.
  • C: the corridor is clear.
  • M: movement is permitted.

It knows B and the rule (B\land C)\rightarrow M.

Must M be true, must it be false, or is it undetermined?

Lecture 16 gave us a language and its truth conditions. Now we ask what an agent can conclude from several sentences together. B, C, and M are defined for this robot example and keep these meanings throughout it.

Take a vote and ask what is missing. The answer is undetermined: B alone does not establish C. The rule is a sufficient condition for permission, not a biconditional or a command to move. Return to this question after identifying all models.

Facts, Rules, and a Query

A knowledge base (KB) is a collection of sentences assumed true.

Role Robot example
Fact B: the battery is ready
Rule (B\land C)\rightarrow M
Query Does M follow from these sentences?

All sentences must hold together:

\text{KB}=B\land\bigl((B\land C)\rightarrow M\bigr)

Inference finds consequences of the encoded facts and rules. It does not verify that a sensor report is correct.

A fact and a rule are both formulas. A set of KB sentences is interpreted as their conjunction. The query need not be stored in the KB, and it can be a compound formula rather than a single atom.

[Sources] - AIMA Chapter 7, knowledge-based agents. Original robot encoding. [/Sources]

Assignments and Models

An assignment gives every atom T or F. A model of the KB is an assignment that makes every KB sentence true.

\text{KB}=B\land\bigl((B\land C)\rightarrow M\bigr)

The KB leaves three possible worlds. T = true, F = false.

Read each tile in B, C, M order. The top row has B=true. The second tile, B=true, C=true, M=false, violates the implication. The remaining three top-row worlds are models. All bottom-row worlds fail because the KB includes B as a fact, even when the implication itself is true.

Textbooks sometimes call any assignment a model and then ask whether it satisfies a sentence. Here, a model of the KB always means a satisfying assignment. These are logical possibilities under the assumptions, not probability estimates.

Entailment

\text{KB}\models\alpha

Read: “The KB entails \alpha.” The query \alpha is true in every model of the KB.

To disprove entailment, find one world where the KB is true and the query is false.

Alpha names the query formula. The double turnstile is the semantic entailment symbol. The diagram depicts an entailed query in general, not yet the robot query M. The query can be true outside the KB’s models, so the reverse inclusion is unnecessary.

The Robot’s Permission Is Undetermined

The three models of B\land((B\land C)\rightarrow M):

Model B C M
1 T T T
2 T F T
3 T F F

A countermodel satisfies the KB but makes the query false.

\text{KB}\models B: all three models have B=\text{true}.

\text{KB}\not\models M: model 3 is a countermodel.

\text{KB}\not\models\neg M: model 1 is a countermodel.

Not entailed does not mean false. The KB permits both values of M.

Return to the opener. Ask students to identify a countermodel before each reveal. Model 2 also disproves entailment of NOT M. These three assignments exhaust the KB models over B, C, M.

The distinction is about what follows from our knowledge. Every individual assignment still has only the two classical truth values. Treating an unreported fact as false would be an extra closed-world assumption.

Validity and Satisfiability

Satisfiable: at least one assignment makes the formula true.

Classification Across all assignments Example
Valid / tautology Always true P\lor\neg P
Unsatisfiable / contradiction Always false P\land\neg P
Contingent Sometimes true, sometimes false P\rightarrow Q

For P\rightarrow Q, give one satisfying and one falsifying assignment.

P=\text{false},Q=\text{false} satisfies it. P=\text{true},Q=\text{false} falsifies it.

Valid and contingent formulas are both satisfiable.

Validity classifies a single formula across all assignments. Entailment relates a KB to a query. The table’s three categories are mutually exclusive and exhaustive. Satisfiable is a broader yes/no property, not a fourth exclusive category.

An implication is not automatically valid. Remind students of its one violating row rather than treating the arrow as a proof that Q is true.

[Sources] - AIMA Chapter 7, validity and satisfiability. [/Sources]

Entailment as a SAT Test

The Boolean satisfiability problem (SAT) asks whether a formula has a satisfying assignment.

\text{KB}\models\alpha \quad\Longleftrightarrow\quad \text{KB}\land\neg\alpha\text{ is unsatisfiable}

\text{KB}\land\neg\alpha What it tells us
Has a satisfying assignment A countermodel exists: \alpha does not follow
Has no satisfying assignment \alpha follows from the KB

This is refutation: assume the conclusion is false and look for a contradiction with the KB.

A consistent KB has at least one model. Check this first: C\land\neg C has none and entails every query in classical logic.

Explain the negated query in words: can the premises all hold while the proposed conclusion fails? No such world means entailment. The negation is essential.

The consistency warning concerns classical logic. If the KB has no models, the universal condition for entailment is vacuously true. This does not make contradictory sensor reports trustworthy or make every claim about the physical world true. Repair the premises before interpreting an entailment result as useful evidence.

[Sources] - AIMA Chapter 7, proof by refutation and satisfiability. - https://inst.eecs.berkeley.edu/~cs188/textbook/logic/inference.html [/Sources]

Model Checking

Conceptual pseudocode: enumerate complete truth assignments.

def entails(kb, query):
    symbols = symbols_in(kb, query)
    for model in all_assignments(symbols):
        if evaluate(kb, model):
            if not evaluate(query, model):
                return False
    return True
  • symbols_in: collect distinct atoms from both inputs.
  • all_assignments: enumerate all 2^n assignments for n atoms.
  • evaluate: apply the connectives’ truth tables.

Why is return True after the loop?

One countermodel gives False. True requires exhausting the loop.

The helpers describe operations, not a complete runnable Python implementation. Follow the highlights: enumeration, testing a model, and accepting only after exhaustion. Rows violating the KB do not constrain the query. This procedure also returns True for an inconsistent KB, as classical semantics requires.

Use the robot’s model 3 as a witness for query M. If querying a fresh atom X, symbols_in must include X even though it is absent from the KB. Counting 2^n assignments omits the additional cost of evaluating each formula.

Entailment and Derivation

Notation Meaning
\text{KB}\models\alpha True in every KB model: a statement about meaning
\text{KB}\vdash\alpha Derived by our proof rules: a statement about a proof

Sound: every derived conclusion is entailed. Complete: every entailed conclusion can be derived.

Read the single turnstile as derives and the double turnstile as entails. The arrows in the diagram denote set inclusion, not implication between object-language atoms. A system that is both sound and complete has exactly the right consequences.

Completeness is relative to the logic and proof system. It does not mean that a particular unfinished proof search will find every consequence, or that modus ponens alone proves every propositional entailment. Propositional resolution is complete for refutation when all needed resolvents are explored.

[Sources] - AIMA Chapter 7, inference systems, soundness, and completeness. [/Sources]

Modus Ponens and Modus Tollens

These are inference rules: patterns that derive a conclusion from known premises.

Modus Ponens

\frac{P\rightarrow Q\qquad P}{Q}

The premise P holds, so the rule requires Q.

If the battery is ready, a light is on. The battery is ready. Therefore the light is on.

Modus Tollens

\frac{P\rightarrow Q\qquad\neg Q}{\neg P}

If Q is false, P cannot hold without violating the rule.

The same rule holds, but the light is off. Therefore the battery is not ready.

Knowing Q and P\rightarrow Q does not establish P. The light might have another power source.

Explain the fraction-like notation before using it: the formulas above the line are premises, the formula below is the derived conclusion. The Latin names identify these two reasoning patterns. Ponens affirms the antecedent; tollens denies the consequent. Both are sound because the implication excludes P=true, Q=false.

The light example is a separate simplified rule with generic atoms P and Q. The caveat is logical, not probabilistic: P=false, Q=true satisfies Q and the rule while falsifying P. Affirming the consequent is therefore unsound.

[Sources] - AIMA Chapter 7, standard propositional inference rules. Original battery/light example. [/Sources]

Conjunctive Normal Form

Conjunctive normal form (CNF) is an AND of clauses.

(P\lor\neg Q)\land(Q\lor R)\land\neg R

Term Meaning
Literal An atom or its negation, such as P or \neg Q
Clause An OR of literals, such as P\lor\neg Q
Unit clause Just one literal, such as \neg R

All clauses must hold. Within each clause at least one literal must hold. A unit clause is already a clause and needs no extra literal. P, Q, and R are generic atoms for this section.

Ask which clause forces R to be false. If R=false, the second clause then forces Q=true, and the first forces P=true. This also anticipates unit propagation.

[Sources] - AIMA Chapter 7, CNF. Original annotated draw.io illustration. [/Sources]

CNF Conversion, Step by Step

Convert \neg(P\rightarrow Q)\lor R without changing its models.

Step Equivalent formula
1. Remove the implication \neg(\neg P\lor Q)\lor R
2. Move NOT inward (P\land\neg Q)\lor R
3. Distribute OR over AND (P\lor R)\land(\neg Q\lor R)

The distributive law used in step 3:

X\lor(Y\land Z)\equiv(X\lor Y)\land(X\lor Z)

The result has two clauses. When R=\text{false}, both forms require P=\text{true} and Q=\text{false}.

Predict each expression before revealing it. Step 1 uses P implies Q equivalent to NOT P OR Q. Step 2 uses De Morgan and double negation. Step 3 first commutes R to the left, then substitutes X=R, Y=P, Z=NOT Q in the displayed distributive law.

CNF needs OR over AND. AND over OR is also a valid distributive law, but expansion in that direction produces an OR of conjunctions instead. To remove a biconditional, rewrite P iff Q as (NOT P OR Q) AND (NOT Q OR P). Repeated distribution can greatly enlarge a formula, so this direct method is for small examples.

[Sources] - AIMA Chapter 7, equivalent CNF rewrites. Original worked formula. [/Sources]

CNF Practice: One Clause or Two?

Convert both formulas. First remove the implication.

One Premise, Two Consequences

P\rightarrow(Q\land R)

\neg P\lor(Q\land R) \equiv(\neg P\lor Q)\land(\neg P\lor R)

Two clauses: P requires Q and also R.

Two Conditions, One Consequence

(P\land Q)\rightarrow R

\neg(P\land Q)\lor R \equiv\neg P\lor\neg Q\lor R

One clause: only P and Q together require R.

The position of AND matters. Negating an AND and distributing over an AND are different steps.

Give a short pair exercise before clicking. Keep both answers hidden initially and reveal each solution separately. In the first, distribute OR over AND. In the second, negating the premise changes its AND into OR by De Morgan, so no distribution is needed.

Use P=true, Q=false, R=false to distinguish the original formulas: the first is false but the second is true. This tests whether students changed the rule while rearranging it.

Resolution

Resolution combines two clauses containing a complementary pair, P and \neg P.

P is the pivot atom. A,B are the remaining disjunctions. Add the derived resolvent; keep both parents.

If both parents are true… Then…
P=\text{false} The first clause forces A
P=\text{true} The second clause forces B

Either way, A\lor B is true. Resolution is sound.

P is the pivot atom. A and B here stand for the remaining literals or disjunctions, not the robot’s battery atom. The case split proves soundness without guessing P’s truth value.

Resolution derives a consequence; it generally does not produce an equivalent replacement for both parents. A refutation procedure retains existing clauses and adds the resolvent.

Unit Resolution and the Empty Clause

A unit clause has only one literal, so resolving can leave a shorter clause or no literals at all.

One Literal Remains

\frac{P\qquad\neg P\lor Q}{Q}

The fact P eliminates \neg P. The remaining clause is Q.

No Literals Remain

\frac{P\qquad\neg P}{\bot}

The empty clause, written \bot, cannot be true under any assignment.

Deriving \bot proves the starting clauses cannot all hold together.

The first pattern is modus ponens after rewriting the implication as a clause. Read bottom as contradiction. Some sources denote the empty clause by a square or empty braces. An OR over zero literals is false.

Distinguish the empty clause, which is false, from an empty set of clauses, whose conjunction is true. A resolution derivation of bottom shows inconsistency of the starting clause set. When those starting clauses are KB plus the negated query, this establishes the original query by refutation.

[Sources] - AIMA Chapter 7, unit resolution and the empty clause. [/Sources]

Reachability by Refutation

L: left route open. R: right route open. G: the goal is reachable.

\text{KB}=(L\lor R)\land(L\rightarrow G)\land(R\rightarrow G)

To prove G, add \neg G and convert to clauses:

ID Clause Origin
1 L\lor R At least one route is open
2 \neg L\lor G L\rightarrow G
3 \neg R\lor G R\rightarrow G
4 \neg G Negated query, added for the proof

This is a new example; L and R name two route-open propositions, not costs. Ask whether a reachable goal necessarily tells us which route is open. No: either one or both could be open. The KB is consistent, for example L=true, R=false, G=true satisfies it.

The diagram represents the alternative routes, not a shortest-path search. Clause 4 is a temporary assumption, not a reported fact about the goal. Refutation checks whether it can coexist with the original KB.

A Resolution Proof, Step by Step

Numbers identify clauses. Each new clause records its parents and pivot.

5: resolve 2 and 4 on G to get \neg L.

6: resolve 3 and 4 on G to get \neg R.

7: resolve 1 and 5 on L to get R.

8: resolve 6 and 7 on R to get \bot. Thus \text{KB}\models G.

One click reveals one inference and highlights its parent clauses, connecting arrows, and new result. Step backward to revisit a deduction. Clause 4 is used twice; the two copies in the proof diagram denote the same negated-query clause.

Ask students to predict each resolvent before revealing it. Deriving bottom disproves the extra assumption NOT G when combined with the KB. It proves G, not NOT G. Keep every clause, even when it is no longer used in the displayed derivation. Other valid proof orders are possible.

Resolution Uses One Complementary Pair

Consider P\lor Q and \neg P\lor\neg Q.

Can we cancel both P,\neg P and Q,\neg Q to conclude \bot?

No. P=\text{true},Q=\text{false} satisfies both parent clauses.

Resolve only on P:

\frac{P\lor Q\qquad\neg P\lor\neg Q}{Q\lor\neg Q}

The resolvent is a tautology, not a contradiction. A sound rule cannot derive \bot from satisfiable parents.

This is a useful counterexample to an overgeneralized cancellation rule. Resolving on Q gives P OR NOT P instead. A complementary pair across the two parent clauses is the pivot for one resolution step. Complementary literals in the resulting clause make it tautological, not empty.

Unit Propagation

A unit clause forces its only literal to be true. Substitute that assignment and repeat.

For the route clauses \{L\lor R,\ \neg L\lor G,\ \neg R\lor G,\ \neg G\}:

Like constraint propagation, forced assignments reduce search. If they do not decide the formula, branching may still be needed.

CSP means constraint satisfaction problem, as in Lectures 13-15. The clause NOT G first forces G=false. Simplifying NOT L OR G and NOT R OR G produces the unit clauses NOT L and NOT R. These force both routes closed, making L OR R false.

This is the same inconsistency as the resolution proof, viewed as successive forced assignments. Unit propagation alone is not a complete general SAT solver. No remaining unit clause does not imply a satisfying assignment or unsatisfiability.

[Sources] - AIMA Chapter 7, SAT and unit clauses. - https://inst.eecs.berkeley.edu/~cs188/textbook/logic/inference.html - Original draw.io propagation diagram. [/Sources]

New Facts Change the Robot’s Conclusions

B: battery ready. C: corridor clear. M: movement permitted.

Original KB: B and (B\land C)\rightarrow M.

The rule becomes \neg B\lor\neg C\lor M. Resolving with B gives \neg C\lor M.

Consider these separate updates to the original KB:

Add C: Does M Follow?

\frac{\neg C\lor M\qquad C}{M}

Yes. The rule now has both required conditions.

Add \neg M: Does \neg C Follow?

\frac{\neg C\lor M\qquad\neg M}{\neg C}

Yes. A clear corridor would contradict the rule and known facts.

The original KB left M undetermined. An added fact removes possible worlds.

Allow a brief individual attempt before each reveal. The updates are alternatives, not cumulative: adding C and NOT M together would make this KB inconsistent. For each update students can also filter the three models on the earlier slide.

The second conclusion follows from this encoded sufficient-condition rule and B. It is not a claim that a movement restriction always measures real corridor safety. A refutation proof for either conclusion would add its negation and derive bottom from the displayed unit result.

Takeaways

  • Entailment: the query holds in every KB model.
  • Countermodel: a KB model where the query is false.
  • CNF: an AND of clauses, each an OR of literals.
  • Resolution: use one complementary pair and keep the other literals.
  • Refutation: derive a contradiction from the KB plus the negated query.

An unknown conclusion needs more information. “Not entailed” is not the same as “false.”
