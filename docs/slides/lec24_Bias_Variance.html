Bias, Variance, and Overfitting

How complex should a learned model be?

Parameterized Models

A model is often defined by parameters \theta learned from data.

y=f(x;\theta)

Examples:

  • Linear regression coefficients.
  • Neural network weights.
  • Decision-tree split choices.

Learning means choosing parameters that perform well beyond the training data.

Training Error vs. Test Error

Error Measured on What it tells us
Training error Data used for fitting How well the model fits examples it saw
Test error Unseen data How well the model generalizes

A model can have low training error and still fail the real task.

Linear Regression

Linear regression predicts a continuous output using a weighted sum of features.

\hat{y}=\beta_1x_1+\beta_2x_2+\cdots+\beta_px_p = \mathbf{x}^T\boldsymbol{\beta}

Temperature prediction:

  • x_1=1
  • x_2= humidity
  • x_3= wind speed
  • x_4= humidity squared

Learning the Parameters

Given n training examples, mean squared error is:

\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2

Matrix form:

\min_{\boldsymbol{\beta}} \frac{1}{n}\left\|X^T\boldsymbol{\beta}-\mathbf{y}\right\|_2^2

Training is an optimization problem.

Optimization

For many ML models, parameters are learned with gradient descent or variants such as stochastic gradient descent.

When linear regression has enough well-behaved samples, it also has a closed-form solution:

\tilde{\boldsymbol{\beta}}=(XX^T)^{-1}X\mathbf{y}

Even when optimization succeeds, generalization is a separate question.

Bias and Variance

Bias

Error from overly simple assumptions.

High bias can cause underfitting.

Variance

Error from sensitivity to the training sample.

High variance can cause overfitting.

The classical story: better generalization often requires balancing bias and variance.

Bias-Variance Tradeoff

Linear Regression Cases

Suppose the true relationship is linear.

Case Interpretation Classical behavior
p<s Too few features High bias, low variance
s \leq p < n Enough features, fewer than samples Low bias, rising variance
p>n More features than samples Overparameterized

where s is the number of true features, p is selected features, and n is samples.

Double Descent

Classical bias-variance says test error eventually rises as complexity increases.

Modern models can show double descent:

  • Test error first decreases.
  • Then spikes near the interpolation threshold.
  • Then decreases again as the model becomes even more overparameterized.

This challenges the simple claim that all overfitting is harmful.

Double Descent Curve

Benign Overfitting

Classical theory suggests overfitting harms test performance.

In modern deep learning, some models can fit the training data extremely well and still generalize.

What happens?

  • Training error approaches zero.
  • Test error remains acceptable.

Why it matters

  • It complicates regularization.
  • It motivates newer theories of generalization.

What to Remember

  • Training error and test error answer different questions.
  • Bias is error from simplicity; variance is error from sensitivity.
  • Overfitting means fitting training-specific noise or quirks.
  • Classical generalization has a bias-variance tradeoff.
  • Modern overparameterized models can show double descent and benign overfitting.
