Context Changes a Token’s Representation

Consider the word bank in two sentences:

  • “We rested on the river bank.”
  • “We deposited money at the bank.”

The initial token embedding may be the same. How can the surrounding words change its representation?

Attention lets a position combine information from other positions.

Overview

Transformers were introduced in Attention Is All You Need in 2017.

Applications include:

  • Machine translation.
  • Summarization.
  • Text generation.
  • Language understanding.
  • Vision, audio, and multimodal modeling.

The original model used an encoder and a decoder. Other systems use only one of those components.

Transformers as Autoregressive Models

Decoder-only transformers generate left to right:

p(x_1,\ldots,x_T)=\prod_{t=1}^{T}p(x_t\mid x_{<t})

Why Transformers?

Recurrent neural network (RNN)

  • Processes tokens sequentially.
  • Hidden state is a bottleneck.
  • Hard to parallelize.

Transformer advantage

  • Uses self-attention.
  • Processes known sequence positions in parallel during training.
  • Captures long-range dependencies.

Token Embedding

Given tokens:

a_1,a_2,\ldots,a_n

Each token maps to a vector:

x_i\in \mathbb{R}^{d_e}

Matrix representation:

X= \begin{bmatrix} x_1 & x_2 & \cdots & x_n \end{bmatrix} \in \mathbb{R}^{d_e\times n}

Embedding Choices

Encoding Description
One-hot Sparse, high-dimensional, fixed
Learned embedding Dense vectors trained end-to-end
Pretrained embedding Initialized from existing language representations

Embeddings turn discrete tokens into continuous vectors that neural networks can manipulate.

A Small Embedding Lookup

Three token IDs index columns of an embedding matrix:

E=\begin{bmatrix}1&0&1\\0&1&1\end{bmatrix}.

For token IDs [2,0,2], using zero-based indexing:

X=\begin{bmatrix}1&1&1\\1&0&1\end{bmatrix}\in\mathbb{R}^{2\times3}.

Why do the first and third positions have the same vector here?

They use the same lookup entry. Position information and subsequent attention layers distinguish their contexts.

Attention Setup

We have context embeddings X and query embeddings X_Q.

Learned projections create:

K=W_KX,\qquad Q=W_QX_Q,\qquad V=W_VX

Symbol Role
Query What am I looking for?
Key What information is available?
Value What content should be returned?

Q, K, and V abbreviate query, key, and value. The projection matrices are learned during training.

Query-Key-Value Diagram

Matching uses keys. Mixing uses values. They need not have the same feature dimension.

Shapes Before Numbers

One vector per column. There are n context positions and m queries.

Feature dimensions: d_e for embeddings, d_k for keys/queries, d_v for values.

Quantity Shape
Context X, queries X_Q d_e\times n, d_e\times m
W_K, W_Q d_k\times d_e
K=W_KX, Q=W_QX_Q d_k\times n, d_k\times m
V=W_VX d_v\times n
Scores K^TQ n\times m
Output d_v\times m

Each query receives its own distribution over the n context positions.

Softmax Function

Softmax converts scores into a probability distribution:

\operatorname{softmax}(z)_i = \frac{e^{z_i}}{\sum_{j=1}^{n} e^{z_j}}

Properties:

  • Each output is non-negative.
  • The outputs sum to 1.
  • Larger scores receive larger probabilities.

In attention, softmax turns similarity scores into mixing weights.

Scaled Dot-Product Attention

\operatorname{Attention}(Q,K,V)= V\cdot \operatorname{softmax}\left(\frac{K^TQ}{\sqrt{d_k}}\right)

Interpretation:

  • K^TQ: similarity scores.
  • \sqrt{d_k}: controls the scale of dot products.
  • \operatorname{softmax}: turns scores into weights.
  • V: values are averaged using those weights.

Softmax runs down each column, across keys for one query.

Why Divide by the Square Root?

The dot product adds d_k terms:

q^Tk=\sum_{r=1}^{d_k}q_rk_r.

If the terms are independent, zero-mean, and unit-variance:

\operatorname{Var}(q^Tk)=d_k,\qquad \operatorname{Var}\!\left(\frac{q^Tk}{\sqrt{d_k}}\right)=1.

Scaling helps prevent large dot products from making softmax excessively sharp. The independence assumptions explain the intuition, not an exact law for learned features.

Worked Example: One Query, Three Keys

Use d_k=2, query q=(1,0)^T, and these already-projected vectors:

K=\begin{bmatrix}1&0&1\\0&1&1\end{bmatrix},\qquad V=\begin{bmatrix}2&0&2\\0&2&2\end{bmatrix}.

Position Key Value
1 (1,0)^T (2,0)^T
2 (0,1)^T (0,2)^T
3 (1,1)^T (2,2)^T

These are invented feature vectors, not measurements of word meaning.

Step 1: Compare the Query with Every Key

K^Tq=\begin{bmatrix}1\\0\\1\end{bmatrix}.

Position Dot product Scaled score
1 1\cdot1+0\cdot0=1 1/\sqrt2\approx0.707
2 0\cdot1+1\cdot0=0 0
3 1\cdot1+1\cdot0=1 1/\sqrt2\approx0.707

Positions 1 and 3 match this query equally well.

Step 2: Normalize the Scores

\alpha=\operatorname{softmax}\!\begin{bmatrix}0.707\\0\\0.707\end{bmatrix} \approx\begin{bmatrix}0.401\\0.198\\0.401\end{bmatrix}.

For example, \alpha_1=e^{0.707}/(e^{0.707}+1+e^{0.707}).

The weights sum to 1. A zero score still gets positive weight.

Step 3: Mix the Values

\begin{aligned} o&=V\alpha=\alpha_1v_1+\alpha_2v_2+\alpha_3v_3\\[0.4em] &\approx0.401\begin{bmatrix}2\\0\end{bmatrix} +0.198\begin{bmatrix}0\\2\end{bmatrix} +0.401\begin{bmatrix}2\\2\end{bmatrix}\\[0.4em] &\approx\begin{bmatrix}1.604\\1.198\end{bmatrix}. \end{aligned}

The output is a new feature vector formed from the values. Attention does not have to select exactly one token.

K=\begin{bmatrix}1&0&1\\0&1&1\end{bmatrix},\qquad V=\begin{bmatrix}2&0&2\\0&2&2\end{bmatrix}.

Practice Answer: The Query Changes the Mixture

s'\approx(0,0.707,0.707)^T,\qquad \alpha'\approx(0.198,0.401,0.401)^T.

o'=V\alpha'\approx(1.198,1.604)^T.

What if the query were the zero vector?

All scores would be zero, so weights would be (1/3,1/3,1/3)^T. The output would be the average of all values: (4/3,4/3)^T.

Attention Computation

function Attention(Q, K, V)
scores = KT * Q
scaled = scores / sqrt(d_k)
weights = softmax(scaled, axis=0)
return V * weights

* means matrix multiplication. With keys in rows of scores, axis 0 normalizes across keys.

Self-Attention and Cross-Attention

Kind Query source Key and value source
Self-attention The sequence itself The same sequence
Cross-attention One sequence Another sequence or representation

For self-attention, X_Q=X, but generally Q\ne K\ne V because their projections differ.

In translation, what might a decoder’s query attend to through cross-attention?

Representations of the source sentence produced by the encoder.

Parallel Computation

Attention for many queries can be computed together:

\text{Attention}(X_Q)= \begin{bmatrix} \text{Attention}(\tilde{x}_1)&\cdots&\text{Attention}(\tilde{x}_{n_q}) \end{bmatrix}

All query positions can be processed in parallel, which is a major speed advantage over RNNs during training.

Parallel Training, Sequential Generation

Training on a known sentence Generating a new sentence
All input tokens are already available Future tokens have not been chosen
Compute many positions together Produce the next token, then extend the prefix
A causal mask prevents looking ahead Each new token depends on the growing prefix

Parallel attention does not make ordinary autoregressive generation fully parallel across future tokens.

The next lecture develops causal masks, multiple heads, and the complete transformer block.

The Cost of Dense Attention

Self-attention over n positions forms an n\times n score matrix per head.

Sequence length Number of scores
1{,}000 1{,}000{,}000
2{,}000 4{,}000{,}000
4{,}000 16{,}000{,}000

Why does doubling the context length create more than twice as many pairwise interactions?

Every position compares with every position, so the count is quadratic. Dense attention arithmetic is O(n^2 d_k + n^2 d_v) per head, excluding projections. Optimized kernels can avoid storing the entire score matrix, so do not claim that every implementation allocates n^2 scores simultaneously.

The Formula in Row-Vector Notation

Many papers and libraries store positions as rows. Write Q_r=Q^T, K_r=K^T, and V_r=V^T.

O_r=\operatorname{softmax}\!\left(\frac{Q_rK_r^T}{\sqrt{d_k}}\right)V_r.

  • Here softmax runs across each row.
  • This is the transpose of the column-vector computation used today.
  • Check the layout and normalization axis before translating a formula into code.

PyTorch’s scaled_dot_product_attention uses the row-oriented sequence and feature layout in its last dimensions. The numerical example is unchanged by transposing the inputs and output. This slide reconciles the course notation with the primary paper and software documentation without changing the convention in Lecture 38.

Exit Check

  1. Which objects determine the attention weights?
  2. Which objects are averaged to form the output?
  3. Does self-attention mean that queries and keys are identical?

Queries and keys, values, and no: self-attention uses the same source sequence but different learned projections.

What to Remember

  • Transformers use attention instead of recurrence.
  • Autoregressive transformers generate next tokens left to right.
  • Token embeddings are continuous vector representations.
  • Attention forms query, key, and value projections.
  • Scaled dot-product attention computes weighted sums of values.
  • Attention parallelizes sequence processing.
