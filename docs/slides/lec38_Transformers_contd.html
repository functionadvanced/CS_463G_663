From Attention to a Language Model

Recall: queries Q and keys K set weights; values V supply content. Each vector is a column, and d_k is the number of key/query features:

O=V\,\operatorname{softmax}_{\text{columns}}\!\left(\frac{K^TQ}{\sqrt{d_k}}\right).

A block is a repeated group of neural-network operations. A language model needs complete blocks and an output head, not just one attention calculation.

The pipeline is a decoder-only autoregressive language model. Encoder-only and encoder-decoder Transformers also exist. Softmax runs down each score column across keys, as in Lecture 37. The generic token/position stage includes either added position vectors or position-aware operations inside attention. The lecture develops the supplied Beamer and TikZ source, with the same column-vector convention. Reference: Vaswani et al. (2017), Attention Is All You Need, https://arxiv.org/abs/1706.03762.

Several Attention Heads

An attention head is one attention computation with its own learned query, key, and value projections. Multi-head attention (MHA) runs several heads on the same input.

Concatenate means stack the head outputs end to end, preserving their separate coordinates. A learned output projection W_O mixes those coordinates.

Heads can learn different relationships. They are not required to specialize in predefined roles or to produce different attention patterns.

Each head uses the single-head computation from Lecture 37. For self-attention all heads receive the same source sequence, but their projection parameters differ. Concatenation stacks features, not positions. For H heads with d_v output features each, W_O has shape d_e by H*d_v. With n query positions the final output has shape d_e by n. H is the number of heads, not the query count. Reference: Vaswani et al., Section 3.2.2.

A Two-Head Example

For one query, suppose the head outputs are u_1=(2,0)^T and u_2=(0,3)^T.

Concatenation gives four features, not their two-feature sum:

c=\begin{bmatrix}u_1\\u_2\end{bmatrix} =\begin{bmatrix}2\\0\\0\\3\end{bmatrix}.

With output projection W_O=\begin{bmatrix}1&0&1&0\\0&1&0&1\end{bmatrix}, what is W_Oc?

W_Oc=(2,3)^T. The 2\times4 projection returns two features. Learned weights can mix the head coordinates differently.

These head outputs and the output matrix are constructed examples, not trained parameters. W_O is not required to sum coordinates. In a real model it is learned jointly with the per-head projections. For multiple queries, the same output projection acts on each concatenated output column independently.

Training Targets Are Shifted

Teacher forcing uses the correct earlier tokens from a training example. For the sentence “The sky is blue”, the target at each input position is the next token:

A causal mask blocks attention to later input positions. All training inputs may be loaded together, but each prediction must use only its allowed prefix.

At input position 2 (sky), can the model read input position 3 (is) to predict is?

No. That would reveal the target itself. Position 2 may read only The and sky.

Positions in this example are numbered from 1. The input at i predicts the token at i+1. Beginning and end tokens can also be trained; the diagram shows an interior three-target segment. A causal mask must be respected at every self-attention layer, not only at the final prediction. Teacher forcing does not authorize future-token leakage.

The Mask in Column-Vector Notation

In the score matrix, row j is a key position and column i is a query position. The additive mask has M_{j,i}=0 when j\le i, and -\infty otherwise.

A=\operatorname{softmax}_{\text{columns}}\!\left(\frac{K^TQ}{\sqrt{d_k}}+M\right).

If the three scores in query column 2 were all zero before masking, what weights would result?

(1/2,1/2,0)^T. Mask before softmax: blocked positions receive zero weight, and allowed weights still sum to one.

The allowed triangle is upper triangular because this lecture puts keys in rows and queries in columns. It is transposed in common row-vector formulas. Column 2 permits key positions 1 and 2, blocking key 3. An ordinary finite score of zero is not a blocked score: exp(0)=1, while exp(-infinity)=0. Do not simply zero some weights after softmax without renormalizing. Every query here can attend to itself, so no column is completely masked. Padding masks, batching, and dropout are omitted.

Causal Attention Computation

Inputs are already projected for one sequence. @ is matrix multiplication; n counts positions and dk counts key/query features.

function CausalAttention(Q, K, V)
n, dk = Columns(Q), Rows(K)
scores = (Transpose(K) @ Q) / sqrt(dk)
for i = 1, …, n
for j = i + 1, …, n
scores[j, i] = -infinity
weights = Softmax(scores, axis=0)
return V @ weights

Axis 0 normalizes down each query column, across keys. The inner loop is empty when i = n.

The mask permits parallel training positions without allowing a prediction to use future input.

This is one-based pseudocode for equally many key and query positions, not runnable Python or a cached single-query decode call. A vectorized library operation normally constructs the same mask without these explicit loops. Rows are keys and columns are queries; use scores[j,i], not scores[i,j]. Reveal the dimensions, scores, index loops, blocked entries, then normalization and value mixture. Stable softmax subtracts a finite allowed maximum before exponentiation. Apply the causal restriction within every self-attention head at every layer.

Token Order Needs a Signal

Attention alone, without position information or a causal mask, has no built-in coordinates for first, second, or third. Order can change meaning:

A positional encoding supplies location information. One approach adds position vector p_t to token embedding e_t:

z_t=e_t+p_t.

Content says which token; a position signal says where it occurs. Position vectors may be learned or computed from a fixed rule.

Without positional signals or order-dependent masks, jointly permuting the inputs of self-attention permutes its outputs in the same way: permutation equivariance, not invariance of the entire output sequence. With a fixed query, consistently permuting key/value pairs leaves their weighted sum unchanged. A causal mask already introduces an order-dependent restriction, so do not claim that any causal model without added positional vectors is completely order-blind. The arithmetic results in the diagram illustrate meaning, not actual model outputs.

Sinusoidal Position Vectors

A sinusoid is a sine or cosine wave. The original Transformer uses pairs of waves that vary at different rates. For even embedding size d_e:

p_t[2r]=\sin(t\omega_r),\qquad p_t[2r+1]=\cos(t\omega_r), \qquad \omega_r=10000^{-2r/d_e}.

Here t=0,1,\ldots is position, r=0,\ldots,d_e/2-1 indexes feature pairs, and \omega_r is the angle change per position in radians.

For the first pair, t=0 gives (0,1) and t=1 gives approximately (0.841,0.540). Multiple rates supply position signals at different scales.

The figure uses d_e=8, for which omega_0=1 and omega_1=0.1; the other pairs have rates 0.01 and 0.001. Curves show the continuous functions for intuition, but sequence positions are integers. Sine and cosine in the same pair share a rate. The two-dimensional pair at t+delta is a rotation of that at t with angle depending on delta; the trigonometric derivation is optional. Fixed encodings can be evaluated outside the training length, but that alone does not guarantee reliable long-context extrapolation. Reference: Vaswani et al., Section 3.5.

Rotary Position Embedding

Rotary Position Embedding (RoPE) rotates feature pairs in queries and keys. Let R(\phi) be a 2D rotation by angle \phi, i,j the query/key positions, and \theta the angle step per position:

\tilde q_i=R(i\theta)q_i,\qquad \tilde k_j=R(j\theta)k_j.

Below, use q_i=k_j=(1,0)^T and \theta=\pi/2: a quarter turn per position.

\tilde q_i^T\tilde k_j=q_i^T R((j-i)\theta)k_j.

The positional factor uses offset j-i; query/key content still matters.

Jianlin Su et al. (2021), RoFormer: Enhanced Transformer with Rotary Position Embedding.

The toy figure uses theta=pi/2 to make quarter-turns visible; actual RoPE uses multiple rates across feature pairs, not this angle for every pair. Here i is a query position and j a key position. For R(phi)=[[cos(phi),-sin(phi)],[sin(phi),cos(phi)]], R(i theta)^T R(j theta)=R((j-i)theta). The content vectors in this example are held fixed while both positions shift; general contextualized queries and keys need not be fixed when the input changes. RoPE does not guarantee successful extrapolation to arbitrary context lengths.

Feedforward Layers and Residuals

A feedforward network (FFN) transforms each position independently:

f(x)=W_2\,\operatorname{ReLU}(W_1x+b_1)+b_2.

W_1,W_2 are learned matrices and b_1,b_2 are biases. ReLU (rectified linear unit) is \max(0,a) for each feature a.

A residual connection (or skip connection) adds the input back: y=x+f(x). If f(x)=0, then y=x.

Attention mixes positions; the FFN transforms features. Residuals add refinements to the input.

The illustrated f(x)=(1,0)^T is obtained, for example, with two identity weight matrices and zero biases, so f reduces to ReLU. That is a toy choice, not a trained FFN or the usual expanded intermediate dimension. In a full model the FFN normally has a larger intermediate feature size; activation variants also exist. A residual addition requires matching input and output dimensions. The direct identity path helps information and gradients propagate, without guaranteeing optimization success. Residual additions are also used around attention, not only around the FFN.

Layer Normalization

Layer normalization (LN) normalizes the features of one token vector, rather than averaging different sequence positions.

For feature x_a, let \mu be the mean of that vector’s features and v their mean squared deviation from \mu:

y_a=\gamma_a\frac{x_a-\mu}{\sqrt{v+\epsilon}}+\beta_a.

\gamma_a and \beta_a are learned scale and shift parameters; \epsilon>0 is a small constant that prevents division by zero.

The example uses unit scales and zero shifts, ignoring \epsilon only for hand arithmetic. Actual implementations retain it.

For a d_e-feature vector, mu=(sum_a x_a)/d_e and v=(sum_a (x_a-mu)^2)/d_e. This is the population/biased variance, not the sample estimator with denominator d_e-1. LN computes these statistics separately for each token, in both training and inference. Learned scale and shift mean the final output need not itself have zero mean or unit variance. Reference: https://docs.pytorch.org/docs/stable/generated/torch.nn.LayerNorm.html.

A Complete Pre-LN Block

Pre-LN means layer normalization comes before each attention or FFN operation. For input matrix X, call the intermediate result U and output Y:

\begin{aligned} U&=X+\operatorname{MHA}_{\text{causal}}(\operatorname{LN}(X)),\\ Y&=U+\operatorname{FFN}(\operatorname{LN}(U)). \end{aligned}

LN and FFN act on each column; causal MHA mixes allowed columns. Stack several blocks to build the model.

Both additions preserve the embedding dimension. The second residual uses U, not the original X, which is why the equations name the intermediate explicitly. The MHA function here includes its learned projections, concatenation, output projection, and causal mask. LN has separate learned parameters at the two sites. A common decoder-only pre-LN model has another final LN before its output head. In the original post-LN Transformer, normalization follows each residual sum: U=LN(X+MHA(X)), Y=LN(U+FFN(U)). This lecture illustrates one common block layout, not every architecture.

From the Final Vector to a Token

Inference uses a trained model without updating its parameters. Let h_n be the final normalized representation at the last prefix position, after all blocks.

The vocabulary is the set of output tokens. An output head produces logits, unnormalized scores for those tokens:

\ell=W_{\text{vocab}}h_n+b,\qquad p=\operatorname{softmax}(\ell).

W_{\text{vocab}} and b are learned weights and biases. These probabilities are over vocabulary tokens, not attention’s context positions.

The three-token vocabulary and logits are constructed examples. The complete model produces h_n; a single attention-head output should not be presented as the whole final language-model state. Some models tie output weights to the token embedding matrix, but that is optional, not a requirement of attention. The softmax here runs over vocabulary entries, unlike the column-wise context-position softmax. Logarithms in the toy logits are natural logs: exp(log 4)=4, exp(log 2)=2, and exp(0)=1.

Temperature Changes the Distribution

Temperature is a positive sampling setting T. For vocabulary logit \ell_i:

p_i(T)=\frac{\exp(\ell_i/T)}{\sum_j\exp(\ell_j/T)},\qquad T>0.

Using the same toy logits (\log4,\log2,0) for blue, gray, and green:

Lower T sharpens; higher T flattens. Greedy decoding chooses a highest-scoring token instead of sampling.

Low positive temperature still allows randomness. It does not change learned weights or guarantee correctness.

The bars use unrounded probabilities; labels round to three decimals. At T=0.5 the unnormalized masses are 16,4,1; at T=2 they are 2,sqrt(2),1. Positive temperature preserves logit ranking. As T approaches zero a unique maximum gets probability approaching one; ties require care. Software may treat T=0 as a special greedy option, but it is not a valid substitution into this formula. Higher temperature is not a guarantee of useful creativity or factuality.

Top-k Sampling Removes Candidates

Top-k sampling keeps the k highest-scoring vocabulary tokens, removes the others, and renormalizes the remaining probabilities so they sum to 1.

For T=1 and k=2, retain blue and gray from the same toy distribution:

What are the new probabilities? What happens when k=1?

p'(\text{blue})=(4/7)/(6/7)=2/3, p'(\text{gray})=1/3, and p'(\text{green})=0. With k=1, only one top token remains: greedy decoding, after resolving any tie.

The figure displays the filtering and retained mass, not the answer probabilities, until the answer reveal. One implementation sets excluded logits to -infinity before softmax. Lowercase k is the candidate cutoff, not the key matrix K. Positive temperature and top-k play different roles: one changes relative probabilities, the other changes the permitted set. This slide does not prescribe a universally best cutoff or temperature.

Reuse Keys and Values During Generation

A key-value (KV) cache stores earlier keys and values at each attention layer. With causal attention and fixed parameters, future tokens cannot change those earlier representations.

Prefill processes the prompt once. Subsequent decode steps add a token, compute its new per-layer projections, and reuse cached earlier pairs.

Caching avoids recomputing the old prefix. The new query still reads growing context, so cache memory and attention work per new token still grow with context length.

The diagram follows one layer; every layer maintains its own cache. At a decode step the model computes the latest token’s representation through the layers and predicts the following token. Cached keys include the position transformation when the architecture uses it. For fixed head dimensions, dense single-query attention has work linear in the number of cached positions, and KV storage grows linearly with that number; total model cost also includes projections and FFNs. Cache validity assumes unchanged causal model, prefix, and position conventions. It is not a general reuse rule for bidirectional encoders. Reference: https://huggingface.co/docs/transformers/en/cache_explanation.

Perplexity Checks Token Prediction

Perplexity (PPL) measures prediction of the true tokens in held-out data, meaning data not used to fit the parameters. It exponentiates the average negative log probability:

\operatorname{PPL}=\exp\!\left(-\frac1N\sum_{t=1}^N\log p(x_t\mid x_{<t})\right).

Here N is the number of scored tokens, x_{<t} is their true earlier context, and \log is the natural logarithm.

For these two tokens, \operatorname{PPL}=(0.5\times0.25)^{-1/2}=\sqrt8\approx2.828. Lower is better prediction on the same data and tokenization, not proof of factual correctness.

The prompt is a fixed condition and is not one of the two scored tokens. This scores an observed continuation, not the probability of a sampled answer. The true prefix includes is before scoring blue. Training uses the same likelihood principle; held-out evaluation tests generalization without parameter updates. Compared scores also need compatible context-window and evaluation protocols. Reference: https://huggingface.co/docs/transformers/en/perplexity. BLEU and ROUGE are other task-specific text metrics; this concise lecture focuses on next-token likelihood rather than introducing their detailed definitions.

Image Patches Can Be Tokens

A Vision Transformer (ViT) represents an image as a sequence of small patches, rectangular image regions, rather than word IDs.

For this 8\times8 grayscale image, 4\times4 patches give 4 patch tokens. Flattening lists a patch’s 16 pixel values in a fixed order. A learned linear projection maps each vector to 8 features, then adds its position vector.

An extra learned vector, the class token, can collect image information whose final representation is used for classification.

Alexey Dosovitskiy et al. (2020/2021), An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale.

The bitmap is an invented teaching pattern, not a dataset image or trained model output. Grayscale means one pixel channel. With four non-overlapping 4-by-4 patches, each flattened patch has length 16; a projection to dimension 8 has weight shape 8 by 16, plus an 8-feature bias. Every patch uses the same learned projection. Positional vectors preserve spatial layout; a class token is an additional token, so this toy sequence would have five inputs if it includes that token. Original ViT uses an encoder with attention over the whole image, not a causal language-model mask. Its paper title’s 16x16 patch size is not the patch size of our toy example.

Diffusion Can Use a Transformer

A Diffusion Transformer (DiT) uses Transformer blocks as a denoiser, a model for iterative noise removal. It operates on patches of a latent, a compressed image representation.

Conditioning supplies extra information: the noise timestep and desired class label. Repeat sampler updates using predicted noise, then decode the final latent to pixels.

The denoiser mixes all image patches together; it does not generate words or patches left to right.

William Peebles and Saining Xie (2022), Scalable Diffusion Models with Transformers.

This is a simplified redrawing of the supplied DiT material. The original model predicts noise and a variance-related output in latent space. Conditioning enters its blocks through adaptive normalization and residual scaling; those details are not required to read the pipeline. A U-Net is another possible denoising backbone, using spatial downsampling/upsampling and skip connections rather than a sequence of patch-attention blocks. DiT does not replace the diffusion sampler or the image decoder. The original supplied architecture figure remains available at imgs/lec35/DiT_structure.png and is credited on the asset page. Do not infer that every current image-generation product uses this exact architecture.

Quick Check

1. Why mask scores before softmax, instead of just setting some final weights to zero?

Allowed positions must still have weights summing to 1. Pre-softmax masking excludes future keys while normalizing the permitted ones.

2. In the second residual stage, should the skip path add X or the intermediate U?

Add U: Y=U+\operatorname{FFN}(\operatorname{LN}(U)).

3. Does a KV cache make future autoregressive tokens independent?

No. It reuses earlier calculations. The next distribution still depends on the actual prefix chosen so far.

Takeaways

  • Multiple heads learn separate query/key/value projections; concatenate, then project their outputs.
  • Causal masks protect next-token training; position signals encode location.
  • FFNs, residuals, and LN turn attention into stackable blocks.
  • Sampling settings change choices; KV caches reuse earlier work.
  • ViT and DiT apply Transformer computations to image patches.
