Learning a Distribution

Generative machine learning (ML) learns a distribution from which we can sample data.

What Is Generative ML?

Generative ML focuses on modeling:

p_\theta(x)

so that samples from p_\theta look like samples from the real data distribution p(x).

Applications:

  • Image, video, music, and text generation.
  • Drug discovery and materials science.
  • Game assets and virtual environments.
  • Data augmentation.

Where Generative Models Fit

Term Meaning
Artificial intelligence (AI) The broader field of intelligent systems
Machine learning (ML) Learning patterns or decisions from data
Deep learning (DL) ML using multilayer neural networks
Generative modeling Learning a data distribution and producing samples

Generative models can be deep or non-deep. Even a fitted categorical distribution can generate samples.

Generative vs. Discriminative

Model type Learns Example output
Discriminative p(y\mid x) or a decision boundary digit class 3 vs. 8
Generative p(x) or p(x\mid c) a new image, sentence, molecule

Classification asks “what label?” Generation asks “what could a realistic example look like?”

A Tiny Dataset We Can Model Exactly

Imagine three possible 2\times2 binary images, called A, B, and C.

The empirical distribution is p(A)=0.5, p(B)=0.3, p(C)=0.2.

Would a generator that always returns A reproduce this distribution?

Sampling Is Different from Taking the Maximum

Draw u uniformly from [0,1) and use cumulative probability intervals.

Which images do u=0.12, u=0.72, and u=0.93 select?

A, B, and C. Always choosing \arg\max_x p(x) would output only A, eliminating the other valid patterns.

Training Objective

Goal:

p_\theta(x)\approx p(x)

A common objective is negative log-likelihood (NLL):

\mathcal{L}(\theta)= \mathbb{E}_{x\sim p(x)} [-\log p_\theta(x)]

For a discrete distribution, this is:

\mathcal{L}(\theta)=H(p)+D_{\mathrm{KL}}(p\parallel p_\theta).

H(p) is entropy, independent of \theta. Kullback-Leibler (KL) divergence measures distribution mismatch in this direction.

This identity uses the true or empirical data distribution and appropriate support. We estimate the expectation with samples. Some generative models optimize a bound or a different objective rather than evaluating exact likelihood. For continuous data, p is a density, not a probability assigned to an exact point.

Likelihood Practice: Which Model Fits?

Ten independent training samples contain five As, three Bs, and two Cs.

Model p_\theta(A) p_\theta(B) p_\theta(C)
M_1 0.5 0.3 0.2
M_2 0.8 0.1 0.1

Average NLL, using natural logarithms:

-\frac1{10}\left[5\ln p_\theta(A)+3\ln p_\theta(B)+2\ln p_\theta(C)\right].

M_2 favors the most common pattern more strongly. Does that make it a better fit to the whole dataset?

Likelihood Answer: Every Observed Pattern Counts

Model Average NLL, in nats
M_1 -(0.5\ln0.5+0.3\ln0.3+0.2\ln0.2)\approx1.030
M_2 -(0.5\ln0.8+0.3\ln0.1+0.2\ln0.1)\approx1.263

Lower is better. M_1 assigns more appropriate probability to B and C.

Matching the most common outcome is insufficient. A model must also account for less frequent observations.

If a model assigns zero probability to an observed discrete pattern, its NLL is infinite. This toy training calculation does not establish generalization. Compare held-out likelihood and other task-appropriate checks on new data.

Evaluation Is Hard

Generative outputs are high-dimensional and often stochastic.

Why simple accuracy does not work:

  • There may be many valid outputs.
  • Exact match can be meaningless.
  • Human perception matters.

Checks include held-out likelihood, sample quality, diversity, and whether the output matches its condition or prompt.

Quality, Coverage, and Memorization

Generator behavior What looks good? What is missing?
Always returns a clean A Every sample is valid Coverage of B and C
Returns many corrupted patterns Outputs differ Sample quality
Copies training examples Familiar, convincing samples Evidence of generalization
Produces varied valid held-out-like patterns Quality and coverage Still needs systematic evaluation

Which failure could you miss by inspecting only the single best generated image?

Discuss all three failures. In the tiny finite categorical example, repeating a pattern is expected; it does not establish memorization. For real high-dimensional datasets, inspect nearest training neighbors, duplicates, held-out performance, and privacy-sensitive content. Diverse samples alone do not prove novelty or correctness.

What Common Metrics Measure

Metric or method Meaning Limitation
NLL Negative log-likelihood on held-out data Not directly available for every model
FID Frechet Inception Distance: compares image-feature distributions Sensitive to features, sample count, and evaluation setup
BLEU Bilingual Evaluation Understudy: reference n-gram overlap Useful mainly for reference-based text evaluation, not universal text quality
Human evaluation Ratings under a defined rubric Cost, variation, and evaluator bias

Use the same evaluation setup when comparing models.

Metric references: Heusel et al. (2017), https://arxiv.org/abs/1706.08500, introduces FID; Papineni et al. (2002), https://aclanthology.org/P02-1040/, introduces BLEU. Reference-based overlap does not measure all aspects of factual correctness or usefulness.

A transformer is an architecture, not a separate training objective. It can support autoregressive or diffusion models.

Autoencoders

z=f_\phi(x),\qquad \hat{x}=g_\theta(z).

Purpose:

  • Compress input into a representation.
  • Reconstruct the input.
  • Learn useful latent features.

Reconstruction Does Not Guarantee Generation

An ordinary autoencoder learns to reconstruct codes produced by its encoder.

What happens if we draw a completely random latent vector and send it to the decoder?

It may fall in a region never visited during training. A small reconstruction error does not guarantee sensible outputs there.

To generate reliably, we also need a useful distribution over latent codes.

Autoencoder vs. VAE Encoder

Autoencoder

The encoder maps the input to one latent point: z=f_\phi(x).

Variational autoencoder

Encoder maps input to a distribution:

q_\phi(z\mid x)=\mathcal{N}\!\left(\mu_\phi(x),\operatorname{diag}(\sigma_\phi^2(x))\right)

VAE training balances reconstruction with a penalty that encourages the encoded distributions to match a chosen prior.

VAE: Training and Generation

During training During generation
Encode an observed x into q_\phi(z\mid x) Draw z\sim p(z), often \mathcal{N}(0,I)
Sample a latent code and reconstruct x Decode the sampled latent code
Optimize reconstruction and KL terms No input image is required

The standard negative evidence lower bound is

\underbrace{\mathbb{E}_{q_\phi(z\mid x)}[-\log p_\theta(x\mid z)]}_{\text{reconstruction term}} +\underbrace{D_{\mathrm{KL}}(q_\phi(z\mid x)\parallel p(z))}_{\text{prior-matching term}}.

The evidence lower bound is abbreviated ELBO in the literature. Only interpret the two terms today; do not derive variational inference. The reconstruction term is a negative conditional log-likelihood, not necessarily squared error. Prior matching encourages sampleable latent structure but does not guarantee perfect generations.

A Latent-Sampling Calculation

For a one-dimensional example, the encoder predicts \mu=2 and \sigma=0.5.

\epsilon\sim\mathcal{N}(0,1),\qquad z=\mu+\sigma\epsilon.

If \epsilon=-1.2, what value goes into the decoder?

z=2+0.5(-1.2)=1.4. This is a training-time sample conditioned on an input. Generation instead samples from the prior.

Diffusion Models

Denoising diffusion models generate data by learning to reverse a gradual noising process.

  • Forward process: add noise.
  • Reverse process: remove noise step by step.
  • Sampling starts from random noise.

Diffusion: Forward and Reverse

The reverse process generates a plausible sample. It does not recover a unique original image from arbitrary noise.

One Forward Noising Step

For a simple scalar example:

x_t=\sqrt{1-\beta_t}\,x_{t-1}+\sqrt{\beta_t}\,\epsilon,\qquad \epsilon\sim\mathcal{N}(0,1).

Let x_{t-1}=1, \beta_t=0.36, and sampled noise \epsilon=-0.5.

x_t=0.8(1)+0.6(-0.5)=0.5. The old signal shrinks while random noise enters. Image diffusion applies the same idea to vectors of pixel or latent values.

What the Denoiser Learns

During training, we know the clean example and the noise we added.

A common parameterization predicts that noise:

\mathcal{L}_{\text{noise}}=\mathbb{E}\!\left[\|\epsilon-\epsilon_\theta(x_t,t)\|^2\right].

  • t tells the network how noisy the input is.
  • A sampler uses the prediction and a noise schedule to update x_t.
  • Generation starts with fresh noise and repeats the updates.

This is the simplified noise-prediction training objective associated with DDPM-style models. Denoising diffusion probabilistic model is abbreviated DDPM. Other parameterizations and samplers exist. The displayed loss is not a complete sampling equation.

Diffusion Paths

Forward noising:

x_0 \rightarrow x_1 \rightarrow \cdots \rightarrow x_T

Reverse denoising during generation:

\tilde{x}_T \rightarrow \tilde{x}_{T-1} \rightarrow \cdots \rightarrow \tilde{x}_0

The model learns many small denoising steps instead of one huge generation step.

Conditional Generation

Instead of p_\theta(x), learn p_\theta(x\mid c).

Condition c Generated object x
Digit label 7 A handwritten image of a seven
A partial sentence A plausible continuation
A text description An image matching the description

Conditioning narrows the requested distribution. It does not eliminate randomness or guarantee factual correctness.

Evaluation Activity

You trained a generator for handwritten digits. It makes sharp images, but nearly every image is a 1.

  1. What did visual sharpness fail to measure?
  2. What plot would reveal the problem?
  3. What additional check would you use for a label-conditioned generator?

Coverage is missing. Compare generated class frequencies with the target distribution. For conditional generation, also check whether each image matches the requested label.

Allow two minutes before revealing. A classifier can help estimate digit frequencies, but its own errors and distribution shift must be considered. Add a manual audit. Do not use the training set alone to claim generalization.

What to Remember

  • Generative models learn to produce realistic new samples.
  • The target is a distribution, not just a label.
  • Evaluation is difficult because many outputs can be valid.
  • VAEs, GANs, autoregressive models, flows, and diffusion models are major families.
  • Diffusion models generate by reversing noise.
