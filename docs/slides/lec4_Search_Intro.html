Classical AI

AI = Representation + Search

  1. Describe the problem.
  2. Choose a useful abstraction for partial solutions.
  3. Define operations that change the representation.
  4. Search through those changes until a solution is found.

Representation defines the world the agent can think in; search decides how it moves through that world.

What Is Search?

  • Search is the process of finding a solution or path in a problem space.
  • It is useful when an agent must reason through possible future states before acting.

Example: Vacuum-Cleaner World

  • State count: 2 \times 2 \times 2 = 8.
  • Vacuum location: Room A or Room B.
  • Room A: clean or dirty.
  • Room B: clean or dirty.
  • Actions: L, R, S.
  • Goal: both rooms are clean.

Example: Eight Queens

  • Place 8 queens on an 8 \times 8 chessboard.
  • No two queens may share a row, column, or diagonal.
  • A search formulation must decide what counts as a state and what counts as an action.

Wikipedia: Eight Queens Puzzle

Eight Queens: Naive vs. Better

Naive Formulation

  • States: any board with 0 to 8 queens.
  • Initial: empty board.
  • Actions: place a queen on any empty square.
  • Goal: 8 queens, none attacking.
  • State space: \sim 10^{15} states.

Better Formulation

  • States: one queen per column, filled left to right.
  • Actions: place a queen in the leftmost empty column without attacks.
  • Goal: 8 queens, none attacking.
  • State space: \sim 2000 states.

Example: Navigation

  • States: current city.
  • Initial: starting city.
  • Actions: drive to a neighboring city.
  • Transition: arrive at the neighboring city.
  • Goal: destination city.

Overview: Uninformed Search

Algorithm Idea
BFS Explore all nodes at the current depth before going deeper.
DFS Explore as far as possible along one branch before backtracking.
UCS Expand the least-cost node first.
DLS Run DFS with a depth limit.
IDS Combine the memory profile of DFS with the completeness of BFS.

Overview: Informed and Specialized Search

Informed Search

  • Greedy Best-First Search
  • A* Search

Uses heuristic information to guide expansion.

Other Search Families

  • Bidirectional Search
  • Local Search
  • Adversarial Search

Use structure from the task to reduce work or model competition.

Tradeoffs

Criterion Meaning
Soundness Returned value is always a solution.
Completeness If a solution exists, it will be found.
Optimality The returned solution is the best possible one.
Time complexity Time required to find a solution.
Space complexity Memory required to find a solution.

“Satisficing” means a solution may not be optimal, but is usually good enough. Learn more on Wikipedia.
