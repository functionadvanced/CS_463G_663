Backpropagation by Hand

This notebook compares PyTorch automatic differentiation with a manual chain-rule calculation for a tiny neural network.

What to notice: every gradient is a local derivative multiplied by upstream derivatives, which is the core idea behind backpropagation.

Forward Pass with Autograd

This cell builds a small network, computes the loss, and lets PyTorch calculate gradients.

import torch

# Set random seed for reproducibility
torch.manual_seed(42)

# Define input (2 features) and target output (scalar)
X = torch.tensor([[0.5, 1.0]], dtype=torch.float32)  # Input shape: (1,2)
y = torch.tensor([[1.0]], dtype=torch.float32)       # Target shape: (1,1)

# Initialize weights and bias
w1 = torch.randn((2, 1), requires_grad=True)  # Weights for input layer (2 → 1 hidden unit)
b1 = torch.zeros(1, requires_grad=True)       # Bias for hidden layer

w2 = torch.randn((1, 1), requires_grad=True)  # Weights for hidden layer → output
b2 = torch.zeros(1, requires_grad=True)       # Bias for output layer

# Learning rate
lr = 0.1

# Step 1: Forward Pass (Layer 1 - Hidden Layer)
z1 = X @ w1 + b1  # Linear transformation
a1 = torch.relu(z1)  # Activation function (ReLU)

# Step 2: Forward Pass (Layer 2 - Output Layer)
z2 = a1 @ w2 + b2  # Linear transformation
output = z2  # Final output

# Step 3: Compute Loss (Mean Squared Error)
loss = torch.mean((output - y) ** 2)

# Print forward pass results
print(f"Output before backpropagation: {output.item():.4f}")
print(f"Loss before backpropagation: {loss.item():.4f}")

# Step 4: Backward Pass (Compute Gradients)
loss.backward()  # Automatically computes gradients using backpropagation
Output before backpropagation: 0.0697
Loss before backpropagation: 0.8655

Breakdown of Manual Gradient Calculation

We use the chain rule to manually compute gradients:

1. Compute Loss Derivative

The Mean Squared Error (MSE) loss is defined as: \[ L = \frac{1}{2} (O - y)^2 \] The derivative of the loss with respect to the output \(O\) is: \[ \frac{\partial L}{\partial O} = O - y \]

2. Compute Gradients for the Output Layer

The output layer is directly connected to the final output: \[ z_2 = a_1 w_2 + b_2 \] where \(a_1\) is the output from the hidden layer.

The gradient of the loss with respect to \(z_2\) is: \[ \frac{\partial L}{\partial z_2} = \frac{\partial L}{\partial O} \cdot \frac{\partial O}{\partial z_2} = (O-y) \cdot 1 \] Since the output \(O = z_2\), the derivative of \(O\) with respect to \(z_2\) is 1.

Now, the gradients for the weights and biases in the output layer are: \[ \frac{\partial L}{\partial w_2} = \frac{\partial L}{\partial z_2} \cdot \frac{\partial z_2}{\partial w_2} = \frac{\partial L}{\partial z_2} \cdot a_1 \] \[ \frac{\partial L}{\partial b_2} = \frac{\partial L}{\partial z_2} \cdot \frac{\partial z_2}{\partial b}= \frac{\partial L}{\partial z_2} \cdot 1 \]

3. Compute Gradients for the Hidden Layer

The hidden layer neurons are activated by the ReLU activation function: \[ a_1 = \text{ReLU}(z_1) \] where \(z_1 = X w_1 + b_1\) is the linear transformation.

The derivative of the activation function is: \[ \frac{\partial a_1}{\partial z_1} =\text{ReLU}'(z_1)= \begin{cases} 1 & \text{if } z_1 > 0 \\ 0 & \text{if } z_1 \leq 0 \end{cases} \]

Now, apply the chain rule to compute the gradients for the hidden layer: \[ \frac{\partial L}{\partial z_1} = \frac{\partial L}{\partial z_2} \cdot \frac{\partial z_2}{\partial a_1} \cdot \frac{\partial a_1}{\partial z_1} \] Since \(z_2 = a_1 w_2 + b_2\), we have: \[ \frac{\partial z_2}{\partial a_1} = w_2 \] Thus, the gradient for \(z_1\) is: \[ \frac{\partial L}{\partial z_1} = \frac{\partial L}{\partial z_2} \cdot w_2 \cdot \text{ReLU}'(z_1) \]

The gradients for the weights and biases in the hidden layer are: \[ \frac{\partial L}{\partial w_1} = \frac{\partial L}{\partial z_1} \cdot X^T \] \[ \frac{\partial L}{\partial b_1} = \frac{\partial L}{\partial z_1} \cdot 1 \]

with torch.no_grad():
    # Step 5: Compute Manual Gradients
    dL_dO = 2 * (output - y) / 1  # Derivative of MSE loss w.r.t. output
    dO_dz2 = 1  # Since output = z2, its derivative is 1
    dL_dz2 = dL_dO * dO_dz2  # Chain rule

    # Gradients for w2 and b2 (Output layer)
    dL_dw2 = dL_dz2 * a1  # dL/dw2 = dL/dz2 * da1/dw2
    dL_db2 = dL_dz2 * 1    # dL/db2 = dL/dz2 * db2/db2

    # Gradients for w1 and b1 (Hidden layer)
    dz2_da1 = w2  # Derivative of z2 w.r.t. a1 (weights from hidden to output layer)
    da1_dz1 = (z1 > 0).float()  # ReLU derivative (1 if z1 > 0, else 0)

    dL_dz1 = dL_dz2 * dz2_da1 * da1_dz1  # Chain rule: dL/dz1 = dL/dz2 * dz2/da1 * da1/dz1
    dL_dw1 = dL_dz1 * X.T  # dL/dw1 = dL/dz1 * X
    dL_db1 = dL_dz1 * 1  # dL/db1 = dL/dz1 * db1/db1

# Print Gradients
print("\nAutomatic Gradients (PyTorch):")
print(f"dL/dw1: {w1.grad}")
print(f"dL/db1: {b1.grad}")
print(f"dL/dw2: {w2.grad}")
print(f"dL/db2: {b2.grad}")

print("\nManual Gradients (Calculated using Chain Rule):")
print(f"dL/dw1: {dL_dw1}")
print(f"dL/db1: {dL_db1}")
print(f"dL/dw2: {dL_dw2}")
print(f"dL/db2: {dL_db2}")

# Step 6: Verify Matching
print("\nChecking if manual and automatic gradients match:")
print(torch.allclose(w1.grad, dL_dw1), "for dL/dw1")
print(torch.allclose(b1.grad, dL_db1), "for dL/db1")
print(torch.allclose(w2.grad, dL_dw2), "for dL/dw2")
print(torch.allclose(b2.grad, dL_db2), "for dL/db2")

# Step 7: Update Weights (Gradient Descent)
with torch.no_grad():
    w1 -= lr * w1.grad
    b1 -= lr * b1.grad
    w2 -= lr * w2.grad
    b2 -= lr * b2.grad

    # Zero out gradients after update
    w1.grad.zero_()
    b1.grad.zero_()
    w2.grad.zero_()
    b2.grad.zero_()

# Step 8: Forward Pass Again (After Weight Update)
z1 = X @ w1 + b1
a1 = torch.relu(z1)
z2 = a1 @ w2 + b2
new_output = z2

# Compute new loss
new_loss = torch.mean((new_output - y) ** 2)

# Print updated results
print(f"\nOutput after weight update: {new_output.item():.4f}")
print(f"Loss after weight update: {new_loss.item():.4f}")
